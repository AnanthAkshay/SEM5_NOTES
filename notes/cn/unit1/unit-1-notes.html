§ 1

Data Communication Fundamentals & Network Topologies

Data communication is the exchange of data between two devices via some form of transmission medium (such as a wire cable or wireless radio link). For data communication to be effective, it depends on four fundamental characteristics: delivery, accuracy, timeliness, and jitter.

5 FIVE COMPONENTS OF DATA COMMUNICATION
  1. Message: The information (data) communicated (text, numbers, pictures, audio, video).
  2. Sender: The device that creates and transmits the data message (workstation, server, phone, video camera).
  3. Receiver: The device that receives the transmitted message (workstation, printer, TV monitor).
  4. Transmission Medium: The physical physical conduit over which the message travels from sender to receiver (twisted-pair wire, coaxial cable, fiber-optic cable, or radio waves).
  5. Protocol: A set of formal rules that govern data communication. It represents an agreement between communicating devices without which two devices may be physically connected but unable to communicate.

Data Flow Modes

Flow Mode Directionality Channel Capacity Utilization Real-world Examples
Simplex Strictly unidirectional. Only one device transmits; the other only receives. 100% of bandwidth dedicated to one direction. Keyboard to CPU, traditional broadcast television, FM radio.
Half-Duplex Bidirectional, but not at the same time. Each station can transmit and receive, but sequentially. Entire capacity shared alternately. Walkie-talkies, CB radio, classic Ethernet collision domain.
Full-Duplex Simultaneously bidirectional. Both stations can transmit and receive concurrently. Capacity divided between directions or carried over separate physical circuits. Telephone network, modern switched full-duplex Ethernet.

Physical Topologies & Structural Formulas

The topology of a network defines how nodes are connected geometrically to one another. Two or more devices connect to a link; two or more links form a topology.

Topology Physical Links Formula I/O Ports per Node Advantages Disadvantages
Mesh (Fully Connected) $$\frac{n(n-1)}{2}$$ $$n - 1$$ Dedicated links (no traffic congestion), robust (failure of one link affects only that link), privacy/security, easy fault isolation. Massive cabling requirement, high cost of hardware and I/O ports, difficult installation.
Star $$n$$ (to central hub/switch) $$1$$ Inexpensive, easy to install and reconfigure, robust (if one link fails, only that node goes down; other links stay active). Single Point of Failure: If the central hub/switch crashes, the entire network is disabled.
Bus $$1$$ long backbone cable + $n$ drop lines $$1$$ (tap) Minimal cabling, easy to install for small footprints. Difficult fault isolation, signal reflection at ends requires terminators, degradation as nodes are added; break in backbone halts whole net.
Ring $$n$$ point-to-point links $$2$$ (repeater in / out) Deterministic access, easy to install, each repeater regenerates weak signals. Unidirectional ring failure breaks entire network (unless dual counter-rotating ring like FDDI is used).
Comparison of Physical Network Topologies
QUICK RECALL
  • 5 Components: Message, Sender, Receiver, Medium, Protocol.
  • Mesh requires $\frac{n(n-1)}{2}$ links and $n-1$ ports per node. Star requires $n$ links to a central hub.
  • Simplex = 1-way; Half-Duplex = 2-way alternate; Full-Duplex = 2-way concurrent.

The OSI 7-Layer Model vs TCP/IP Protocol Suite

The Open Systems Interconnection (OSI) model, developed by the ISO in 1984, is a 7-layer theoretical reference framework. In contrast, the TCP/IP Protocol Suite is the pragmatic, 5-layer hierarchical protocol suite upon which the global Internet is built.

Layer # Layer Name Data Unit (PDU) Core Responsibilities & Duties Primary Protocols
Layer 7 Application Message Provides user interface and network services to applications. File transfers, directory services, web browsing, email access. HTTP/HTTPS, DNS, SMTP, FTP, SSH
Layer 6 Presentation Data Translation (ASCII/EBCDIC), Encryption/Decryption (cryptographic security), and Compression (lossless/lossy). SSL/TLS, JPEG, MPEG
Layer 5 Session Data Dialog control (half/full duplex), Synchronization (inserting checkpoints into data streams for recovery). NetBIOS, RPC, PPTP
Layer 4 Transport Segment / Datagram Process-to-process delivery via port addressing, segmentation & reassembly, connection control, flow control, error control. TCP, UDP, SCTP
Layer 3 Network Packet / Datagram Source-to-destination (host-to-host) delivery, logical IP addressing, routing (path selection), datagram fragmentation. IPv4, IPv6, ICMP, OSPF, BGP
Layer 2 Data Link Frame Hop-to-hop (node-to-node) framing, physical MAC addressing, flow control (feedback), error detection (CRC) and correction. Ethernet (802.3), Wi-Fi (802.11), PPP, ARP
Layer 1 Physical Bits Transmission of raw unstructured bits over physical medium. Mechanical/electrical specifications, line coding, data rates, bit synchronization. RJ-45, V.35, Cat6, Fiber optics
MNEMONIC FOR THE 7 LAYERS

Top-down (Layer 7 → 1): "All People Seem To Need Data Processing"

Bottom-up (Layer 1 → 7): "Please Do Not Throw Sausage Pizza Away"

OSI vs TCP/IP Comparison

Feature / Dimension OSI 7-Layer Reference Model TCP/IP Protocol Suite
Number of Layers 7 Layers (Application, Presentation, Session, Transport, Network, Data Link, Physical) 4 or 5 Layers (Application [merges 7,6,5], Transport, Network/Internet, Data Link, Physical)
Development Approach Theoretical concept first; protocols designed later to fit the layers. Protocols developed first (TCP, IP); model was a description of existing protocols.
Transport Delivery Strictly connection-oriented service at transport layer. Both connection-oriented (TCP) and connectionless (UDP) services.
Network Layer Delivery Supports both connectionless and connection-oriented network services. Strictly connectionless datagram service at Internet layer (IP).
Commercial Dominance Never widely deployed commercially; used primarily as a teaching reference. The de-facto architecture and foundation of the worldwide Internet.
QUICK RECALL
  • Physical = bits (raw signals); Data Link = frames (hop-to-hop / MAC); Network = packets (host-to-host / IP).
  • Transport = segments (process-to-process / port); Application = user network access.
  • Presentation handles Translation, Compression, Encryption; Session handles Dialog Control & Checkpoints.
§ 3

Data and Signals (Time vs Frequency Domain)

Information must be transformed into electromagnetic signals before transmission across a physical medium. Signals can be continuous (analog) or discrete (digital).

CHARACTERISTICS OF A PERIODIC SINE WAVE

A periodic analog sine wave is mathematically represented as:

$$s(t) = A \sin(2\pi f t + \phi)$$
  • Peak Amplitude ($A$): The absolute value of its highest intensity, proportional to the energy carried by the signal (measured in Volts, Amperes, or Watts).
  • Period ($T$) and Frequency ($f$): Period is the time taken to complete one full cycle (seconds). Frequency is the number of cycles per second (Hertz, $\text{Hz}$). They are inverse: $$f = \frac{1}{T}, \quad T = \frac{1}{f}$$
  • Phase ($\phi$): The fractional position of the waveform relative to time zero (measured in degrees or radians).
  • Wavelength ($\lambda$): The physical distance a signal propagates in one period through a medium with propagation speed $c$: $$\lambda = \frac{c}{f} = c \times T$$

Time Domain vs Frequency Domain (Fourier Analysis)

Fourier Analysis proves that any composite periodic signal can be decomposed into an infinite series of simple sinusoidal waves with distinct amplitudes, frequencies, and phases:

Domain Representation Horizontal Axis Vertical Axis Information Displayed
Time Domain Plot Time ($t$) Instantaneous Amplitude ($v$) Shows signal voltage value at each instant of time (oscilloscope view).
Frequency Domain Plot Frequency ($f$) Peak Amplitude ($A$) Shows only the frequency components and their peak intensities (spectrum analyzer view).
SIGNAL BANDWIDTH

The bandwidth of a composite signal is the difference between the highest and lowest frequencies contained in that signal:

$$B = f_{high} - f_{low}$$

Example: If a composite periodic signal contains frequencies from $1000\text{ Hz}$ to $5000\text{ Hz}$, its bandwidth is $B = 5000 - 1000 = 4000\text{ Hz} = 4\text{ kHz}$.

QUICK RECALL
  • $f = 1/T$, $\lambda = c/f$. Phase $\phi$ is the angular offset at $t=0$.
  • Time-domain shows amplitude vs time; Frequency-domain shows peak amplitude vs frequency.
  • Bandwidth $B = f_{high} - f_{low}$.
§ 4

Transmission Impairments & Decibel Calculations

As a signal travels through a physical transmission medium, it undergoes degradation caused by physical imperfections of the channel. The three primary transmission impairments are attenuation, distortion, and noise.

1
Attenuation (Loss of Energy): Signal power dissipates as heat due to the electrical resistance of the conductor. Over long distances, amplifiers or repeaters must regenerate the signal. Quantified using Decibels ($dB$).
2
Distortion (Alteration of Shape): In composite signals, different frequency components travel at different propagation speeds through the medium (delay distortion) and experience different attenuation levels. They arrive at the receiver with shifted phases, altering the composite shape.
3
Noise (Extraneous Interference): Unwanted external energy coupled into the channel:
  • Thermal noise: Random kinetic motion of electrons in conductors (white noise, Johnson-Nyquist noise).
  • Induced noise: Electromagnetic interference (EMI) from motors, transformers, and appliances.
  • Crosstalk: Inductive coupling between adjacent wire pairs.
  • Impulse noise: Sudden voltage spikes from lightning or power surges.

Decibel ($dB$) Formulas

DECIBEL EQUATIONS

For power levels $P_1$ (input) and $P_2$ (output):

$$dB = 10 \log_{10}\left(\frac{P_2}{P_1}\right)$$
  • If $P_2 < P_1$, $dB$ is negative (attenuation / loss).
  • If $P_2 > P_1$, $dB$ is positive (amplification / gain).
  • When power is halved ($P_2 / P_1 = 0.5$): $dB = 10 \log_{10}(0.5) \approx -3.010\text{ dB}$.

For voltages $V_1$ and $V_2$ across equal impedances:

$$dB = 20 \log_{10}\left(\frac{V_2}{V_1}\right)$$

Signal-to-Noise Ratio (SNR)

The Signal-to-Noise Ratio is the ratio of average signal power to average noise power:

$$\text{SNR} = \frac{P_{signal}}{P_{noise}}$$ $$\text{SNR}_{dB} = 10 \log_{10}(\text{SNR})$$

Signal Power through Cascaded Transmission Stages

A signal with an input power of $P_{in} = 10\text{ mW}$ passes through three cascaded transmission segments:

  • Segment 1: Transmission cable with an attenuation of $-3\text{ dB}$
  • Segment 2: In-line amplifier with a gain of $+7\text{ dB}$
  • Segment 3: Secondary cable section with an attenuation of $-3\text{ dB}$

Compute: (a) The net decibel rating of the link, and (b) The final output power $P_{out}$.

Solution:

Part (a): Net decibel rating:

Decibels are additive across cascaded stages:

$$dB_{total} = dB_1 + dB_2 + dB_3 = (-3) + (+7) + (-3) = +1\text{ dB}$$

Part (b): Output power $P_{out}$:

$$dB_{total} = 10 \log_{10}\left(\frac{P_{out}}{P_{in}}\right) \implies 1 = 10 \log_{10}\left(\frac{P_{out}}{10}\right)$$ $$\log_{10}\left(\frac{P_{out}}{10}\right) = \frac{1}{10} = 0.1$$ $$\frac{P_{out}}{10} = 10^{0.1} \approx 1.2589$$
$$P_{out} = 10 \times 1.2589 = \mathbf{12.589\text{ mW}}$$
QUICK RECALL
  • Impairments: Attenuation (loss), Distortion (phase shift/delay), Noise (external interference).
  • $dB = 10 \log_{10}(P_2 / P_1)$. Halving power = $-3\text{ dB}$; doubling power = $+3\text{ dB}$.
  • $\text{SNR}_{dB} = 10 \log_{10}(\text{SNR})$. Linear $\text{SNR} = 10^{(\text{SNR}_{dB}/10)}$.
§ 5

Data Rate Limits: Nyquist Bit Rate & Shannon Capacity

A central problem in data communications is determining the maximum theoretical data rate (in bits per second) that can be reliably transmitted over a transmission channel of bandwidth $B$. Two fundamental physical laws dictate these limits: Nyquist's theorem for noiseless channels and Shannon's theorem for noisy channels.

1. Nyquist Bit Rate (Noiseless Channel)

In 1928, Harry Nyquist showed that for an ideal, noiseless channel of bandwidth $B$, the maximum transmission rate depends on the number of discrete signal voltage levels $L$:

NYQUIST BIT RATE FORMULA $$\mathbf{C_{Nyquist} = 2 \times B \times \log_2(L)} \quad \text{[bps]}$$

Where:

  • $B$: Bandwidth of the channel in Hertz ($\text{Hz}$).
  • $L$: Number of discrete signal levels used to represent data ($L \ge 2$).
  • $\log_2(L)$: Number of bits carried per signal element ($r = \log_2 L$).

2. Shannon Capacity (Noisy Channel)

In 1948, Claude Shannon extended this to realistic channels subject to random thermal noise. The Shannon capacity represents the absolute theoretical upper bound for error-free communication:

SHANNON CHANNEL CAPACITY FORMULA $$\mathbf{C_{Shannon} = B \times \log_2(1 + \text{SNR})} \quad \text{[bps]}$$

Where:

  • $B$: Channel bandwidth in Hertz ($\text{Hz}$).
  • $\text{SNR}$: Linear Signal-to-Noise Ratio (NOT in decibels!).
  • Note: As $\text{SNR} \to 0$ (extreme noise), $C \to 0$. Capacity cannot be increased by adding signal levels alone if constrained by noise.
WORKED NUMERICAL 1 • STANDARD EXAM PROBLEM [5 MARKS]

Shannon Capacity of a Noisy Telephone Channel

A standard analog telephone line has a bandwidth of $B = 3000\text{ Hz}$ ($3\text{ kHz}$) and a Signal-to-Noise Ratio of $\text{SNR}_{dB} = 30\text{ dB}$. Compute the theoretical channel capacity.

Step 1: Convert $\text{SNR}_{dB}$ to linear $\text{SNR}$:

$$\text{SNR}_{dB} = 10 \log_{10}(\text{SNR}) \implies 30 = 10 \log_{10}(\text{SNR}) \implies \log_{10}(\text{SNR}) = 3$$ $$\text{SNR} = 10^3 = 1000$$

Step 2: Apply Shannon Capacity Formula:

$$C = B \log_2(1 + \text{SNR}) = 3000 \times \log_2(1 + 1000) = 3000 \times \log_2(1001)$$

Since $\log_2(x) = \frac{\log_{10}(x)}{\log_{10}(2)} = \frac{3.000434}{0.30103} \approx 9.9672$:

$$C = 3000 \times 9.9672 = \mathbf{29,901.68\text{ bps}} \approx \mathbf{29.902\text{ kbps}}$$

Conclusion: Regardless of how many voltage levels modem designers utilize, this line can never reliably exceed ~30 kbps unless the bandwidth or signal-to-noise ratio improves.

WORKED NUMERICAL 2 • COMBINED DESIGN PROBLEM [8 MARKS • HIGH OCCURRENCE]

Signal Levels Required to Attain Shannon Limit

A channel has a bandwidth of $B = 1\text{ MHz}$ and a linear $\text{SNR} = 63$.

  1. Find the Shannon capacity of the channel.
  2. How many signal levels $L$ must be engineered into the transmitter to achieve this data rate under Nyquist's formula?

Part 1: Shannon Capacity:

$$C = B \log_2(1 + \text{SNR}) = 10^6 \times \log_2(1 + 63) = 10^6 \times \log_2(64)$$

Since $64 = 2^6$, $\log_2(64) = 6$:

$$C = 10^6 \times 6 = \mathbf{6\text{ Mbps}}$$

Part 2: Finding Required Signal Levels $L$:

Equate the Nyquist formula to the Shannon limit:

$$C_{Nyquist} = 2 B \log_2(L) \implies 6 \times 10^6 = 2 \times 10^6 \times \log_2(L)$$ $$\log_2(L) = \frac{6 \times 10^6}{2 \times 10^6} = 3 \implies L = 2^3 = \mathbf{8\text{ levels}}$$
The transmitter must support $\mathbf{L = 8\text{ discrete signal levels}}$ (transmitting 3 bits per signal element) to achieve the 6 Mbps channel capacity.
QUICK RECALL
  • Nyquist (noiseless): $C = 2B \log_2(L)$ bps.
  • Shannon (noisy): $C = B \log_2(1 + \text{SNR})$ bps. Always convert $\text{SNR}_{dB}$ to linear first!
  • Shannon gives the upper theoretical ceiling; Nyquist tells how many levels $L$ are required.
§ 6

Digital Line Coding Schemes & Waveforms

Line coding is the process of converting a digital sequence of binary 1s and 0s into a continuous digital signal for physical transmission. A well-designed line coding scheme must prevent DC components, avoid baseline wandering, and support self-synchronization.

Core Properties of Line Coding

  • DC Component: When voltage levels remain constant over time, a direct current (DC) component is created. DC components cannot pass through transformers or AC-coupled circuits and generate heat. A good line coding scheme should have zero DC component.
  • Baseline Wandering: The receiver averages the received signal power to establish a threshold (baseline) for distinguishing 1s from 0s. Long strings of 0s or 1s shift this baseline, causing decoding errors.
  • Self-Synchronization: Receiver and sender clocks must tick at the same rate. Transitions in the middle of bit intervals provide clock synchronization edges.

Taxonomy of Line Coding Schemes

Coding Family Scheme Name Encoding Rule Self-Sync & DC Status
Unipolar NRZ (Non-Return-to-Zero) Positive voltage for binary 1; Zero voltage for binary 0. Poor sync; large DC component; baseline wander.
Polar NRZ-L (Level) Positive voltage represents binary 0; Negative voltage represents binary 1 (or vice versa). No self-sync on consecutive identical bits; DC component present.
NRZ-I (Invert) Transition at the beginning of the bit interval represents binary 1; No transition represents binary 0. Sync on 1s, but fails on consecutive 0s. Baseline wander on long 0s.
Manchester Transition at the center of every bit interval: High-to-Low represents binary 1; Low-to-High represents binary 0 (IEEE 802.3 standard). Perfect self-sync on every bit; Zero DC component; requires $2\times$ bandwidth.
Differential Manchester Transition at center always occurs (clocking). Transition at beginning represents binary 0; No transition at beginning represents binary 1. Perfect self-sync; noise-immune; widely used in Token Ring (802.5).
Bipolar AMI (Alternate Mark Inversion) Zero voltage represents binary 0. Binary 1s alternate between $+V$ and $-V$. Zero DC component; but loses sync on long runs of 0s.
Pseudoternary Inverse of AMI: Zero voltage represents binary 1; binary 0s alternate between $+V$ and $-V$. Zero DC component; loses sync on long runs of 1s.
Line Coding Waveforms for Bit Stream: 0 1 0 0 1 1 0
QUICK RECALL
  • Manchester: Mid-bit transition on every bit. 0 = Low-to-High; 1 = High-to-Low. Zero DC.
  • Differential Manchester: Center transition always occurs. 0 = transition at start; 1 = no transition at start.
  • AMI: 0 = Zero volts; 1s alternate between $+V$ and $-V$. Eliminates DC component.

Important Examination Questions

2-Mark Questions (Short Answer)

2M State the Nyquist bit rate formula and define all symbols.

Answer: $C = 2 B \log_2(L)$ bps, where $B$ is channel bandwidth in Hertz, $L$ is the number of discrete signal voltage levels, and $\log_2 L$ is the number of bits carried per signal element.

2M What is the significance of the mid-bit transition in Manchester encoding?

Answer: The mid-bit transition serves two crucial purposes: (1) It guarantees self-synchronization by providing a clocking edge on every single bit, and (2) It ensures equal positive and negative voltage areas, achieving a zero DC component.

2M Calculate the attenuation in dB when signal power is reduced to one-half.

Answer: $dB = 10 \log_{10}(P_2 / P_1) = 10 \log_{10}(0.5) = 10 \times (-0.30103) = -3.010\text{ dB}$. (Power loss of ~3 dB).

5-Mark Questions (Medium Length)

5M Compare the OSI 7-layer reference model with the TCP/IP protocol suite.

Answer:

  • Layer count: OSI has 7 layers; TCP/IP has 4 or 5 layers (combining Application, Presentation, and Session into one Application layer).
  • Design: OSI was theoretical with protocols defined later; TCP/IP protocols were implemented first and model described them.
  • Network layer: OSI supports both connectionless and connection-oriented services; TCP/IP provides strictly connectionless IP datagrams.
  • Transport layer: OSI is strictly connection-oriented; TCP/IP supports both TCP (connection-oriented) and UDP (connectionless).
5M Explain the three major transmission impairments that degrade signals.

Answer:

  1. Attenuation: Loss of energy as signal propagates through resistance of the medium, measured in decibels ($dB$). Compensated with amplifiers.
  2. Distortion: Change in waveform shape caused by different frequency components propagating at different speeds and suffering different attenuation.
  3. Noise: Unwanted external energy induced onto the transmission line (thermal noise, induced noise from motors, crosstalk between wire pairs, impulse noise spikes).

10-Mark Questions (Long Answer / Comprehensive)

10M Describe the responsibilities and services of each layer of the OSI 7-layer reference model.

Answer Summary:

Detail all 7 layers in top-down or bottom-up order as presented in Section 2:

  1. Physical Layer: Transmission of raw bits, electrical/mechanical specifications, line coding.
  2. Data Link Layer: Hop-to-hop framing, MAC addressing, flow control, CRC error control.
  3. Network Layer: Source-to-destination routing, logical IP addressing, packetizing, fragmentation.
  4. Transport Layer: Process-to-process delivery, port addressing, segmentation, end-to-end flow and error control.
  5. Session Layer: Dialog control (half/full duplex), session synchronization and checkpointing.
  6. Presentation Layer: Syntax translation, encryption/decryption, data compression.
  7. Application Layer: User network interface (HTTP, DNS, FTP, email protocols).
