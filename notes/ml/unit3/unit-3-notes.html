§ 1

Nearest-Neighbor Learning ($K$-NN)

Unlike eager learning algorithms (such as Neural Networks or Decision Trees) that construct an explicit, generalized global model during training, Nearest-Neighbor methods are instance-based or lazy learners. They store training instances directly in memory and defer all computation until a query instance arrives.

Definition: K-Nearest Neighbor Algorithm

Given a query point $\mathbf{x}_q$, $K$-NN locates the $K$ training instances nearest to $\mathbf{x}_q$ according to a distance metric, and predicts the class label via majority vote: $$\hat{y}_q = \operatorname{mode} \big(\{ y_i \mid \mathbf{x}_i \in N_K(\mathbf{x}_q) \}\big)$$ For continuous regression targets, it computes the local arithmetic mean: $$\hat{y}_q = \frac{1}{K} \sum_{\mathbf{x}_i \in N_K(\mathbf{x}_q)} y_i$$

Standard Distance Metrics

  • Euclidean Distance ($L_2$ norm): The straight-line geometric distance: $$d(\mathbf{x}, \mathbf{z}) = \sqrt{\sum_{i=1}^d (x_i - z_i)^2}$$
  • Manhattan Distance ($L_1$ norm / City Block): Sum of absolute coordinate differentials (robust to extreme outliers): $$d(\mathbf{x}, \mathbf{z}) = \sum_{i=1}^d |x_i - z_i|$$
  • Minkowski Distance ($L_p$ norm): Generalized metric family: $$d(\mathbf{x}, \mathbf{z}) = \left( \sum_{i=1}^d |x_i - z_i|^p \right)^{1/p}$$ ($p=1 \implies$ Manhattan; $p=2 \implies$ Euclidean; $p \to \infty \implies$ Chebyshev / Max norm).
Figure 3.1: Voronoi tessellation: Convex polygonal cells determine nearest-neighbor decision boundaries.
Quick Recall

$K$-NN is a lazy, instance-based learner. Small $K$ (e.g., $K=1$) yields low bias but high variance (sensitive to noise); large $K$ yields smooth decision boundaries with higher bias.

§ 2

Weighted $K$-Nearest-Neighbor Algorithm

A major drawback of vanilla $K$-NN is that all $K$ neighbors cast equal votes, regardless of whether a neighbor is $0.01$ units away or $10.0$ units away. In Distance-Weighted $K$-NN (Shepard's Method), each neighbor's vote is scaled inversely proportional to the square of its distance:

Distance-Weighted Voting Formulation

Weight assigned to neighbor $\mathbf{x}_i$: $$w_i = \frac{1}{d(\mathbf{x}_q, \mathbf{x}_i)^2}$$ (If $d(\mathbf{x}_q, \mathbf{x}_i) = 0$, assign the target label of that exact training point directly).

Weighted Classification: $$\hat{y}_q = \arg\max_{v \in V} \sum_{i=1}^K w_i \cdot \mathbb{I}(y_i = v)$$ Weighted Regression: $$\hat{y}_q = \frac{\sum_{i=1}^K w_i y_i}{\sum_{i=1}^K w_i}$$

Solved Problem 1 · Exam Level Instance-Based Learning
Given a 2-dimensional training dataset with $n = 5$ instances: $$A(1, 2) \to +1, \quad B(2, 3) \to +1, \quad C(3, 1) \to -1, \quad D(5, 4) \to -1, \quad E(6, 5) \to -1$$ Classify the query point $\mathbf{x}_q = (2, 2)$ using:
  1. Unweighted $K$-NN with $K = 3$.
  2. Distance-Weighted $K$-NN with $K = 3$ using $w_i = \frac{1}{d(\mathbf{x}_q, \mathbf{x}_i)^2}$.
Step 1: Compute Euclidean Distances to Query Point $\mathbf{x}_q(2, 2)$
  • $d(Q, A) = \sqrt{(1 - 2)^2 + (2 - 2)^2} = \sqrt{(-1)^2 + 0} = \sqrt{1} = \mathbf{1.0000}$ (Label: $+1$)
  • $d(Q, B) = \sqrt{(2 - 2)^2 + (3 - 2)^2} = \sqrt{0 + 1^2} = \sqrt{1} = \mathbf{1.0000}$ (Label: $+1$)
  • $d(Q, C) = \sqrt{(3 - 2)^2 + (1 - 2)^2} = \sqrt{1^2 + (-1)^2} = \sqrt{2} \approx \mathbf{1.4142}$ (Label: $-1$)
  • $d(Q, D) = \sqrt{(5 - 2)^2 + (4 - 2)^2} = \sqrt{3^2 + 2^2} = \sqrt{13} \approx 3.6056$ (Label: $-1$)
  • $d(Q, E) = \sqrt{(6 - 2)^2 + (5 - 2)^2} = \sqrt{4^2 + 3^2} = \sqrt{25} = 5.0000$ (Label: $-1$)
Step 2: Identify $K = 3$ Nearest Neighbors

The 3 closest instances in ascending order are:

$$\text{Rank 1: Point } A \quad (d = 1.0, \; y = +1)$$ $$\text{Rank 2: Point } B \quad (d = 1.0, \; y = +1)$$ $$\text{Rank 3: Point } C \quad (d = \sqrt{2} \approx 1.4142, \; y = -1)$$
Step 3: Unweighted Majority Vote ($K = 3$)
$$\text{Votes for } (+1): 2 \quad (\text{Points } A, B)$$ $$\text{Votes for } (-1): 1 \quad (\text{Point } C)$$ $$\hat{y}_q = \mathbf{+1}$$

$$w_A = \frac{1}{(1.0)^2} = 1.0000$$ $$w_B = \frac{1}{(1.0)^2} = 1.0000$$ $$w_C = \frac{1}{(\sqrt{2})^2} = \frac{1}{2} = 0.5000$$

$$\text{Total Weight for } (+1) = w_A + w_B = 1.0000 + 1.0000 = \mathbf{2.0000}$$ $$\text{Total Weight for } (-1) = w_C = \mathbf{0.5000}$$ $$\text{Since } 2.0000 > 0.5000 \implies \hat{y}_q = \mathbf{+1}$$

Quick Recall

Weighted $K$-NN scales votes by $w_i = 1/d_i^2$, completely neutralizing the influence of distant, uninformative neighbors.

§ 3

Nearest Centroid Classifier (Rocchio)

The Nearest Centroid Classifier compresses every training class into a single representative prototype vector (the class centroid) during training, significantly reducing memory and query evaluation costs:

Mathematical Formulation: Nearest Centroid

For each class $c \in \{1, \dots, C\}$, compute its centroid $\boldsymbol{\mu}_c$: $$\boldsymbol{\mu}_c = \frac{1}{N_c} \sum_{i: y_i = c} \mathbf{x}_i$$ To classify query point $\mathbf{x}_q$, assign it to the class with the closest centroid: $$\hat{y}_q = \arg\min_{c} \|\mathbf{x}_q - \boldsymbol{\mu}_c\|_2$$

Comparison: Nearest Centroid vs. $K$-NN

DimensionNearest Centroid$K$-Nearest Neighbors ($K$-NN)
Decision BoundaryStrictly linear (hyperplanes perpendicular to centroid connectors)Complex, non-linear, piece-wise polygonal boundaries
Storage Complexity$O(C \times d)$ (stores only $C$ centroid vectors)$O(n \times d)$ (stores all $n$ training instances)
Inference TimeExtremely fast: $O(C \times d)$ distance computationsSlow: $O(n \times d)$ distance computations without indexing trees
Non-Convex ClassesFails if classes are non-convex or multimodalAccurately captures arbitrary non-convex manifolds
Quick Recall

Nearest Centroid represents each class by its mean vector $\boldsymbol{\mu}_c$. Fast and linear, but fails when classes are non-spherical or multimodal.

§ 4

Locally Weighted Regression (LWR)

Standard linear regression fits a single global straight line across all training data. In contrast, Locally Weighted Regression (LWR / Loess) is a non-parametric method that fits a customized local linear model in the immediate neighborhood around each specific query point $\mathbf{x}_q$:

LWR Objective Loss Function

Find weights $\boldsymbol{\theta}$ to minimize the locally weighted squared error: $$J(\boldsymbol{\theta}) = \sum_{i=1}^n w_i \big( y_i - \boldsymbol{\theta}^T \mathbf{x}_i \big)^2$$ Where $w_i$ is a Gaussian-like bell-shaped kernel weighting function centered at query point $\mathbf{x}_q$: $$w_i = \exp\left( - \frac{\|\mathbf{x}_i - \mathbf{x}_q\|^2}{2 \tau^2} \right)$$ Where $\tau$ is the Bandwidth Parameter controlling the width of the neighborhood:

  • If $\mathbf{x}_i$ is close to $\mathbf{x}_q$, $\|\mathbf{x}_i - \mathbf{x}_q\| \to 0 \implies w_i \to 1$ (high influence).
  • If $\mathbf{x}_i$ is far from $\mathbf{x}_q$, $\|\mathbf{x}_i - \mathbf{x}_q\|$ is large $\implies w_i \to 0$ (negligible influence).

Closed-form solution for the local parameter vector:

$$\boldsymbol{\theta} = (\mathbf{X}^T \mathbf{W} \mathbf{X})^{-1} \mathbf{X}^T \mathbf{W} \mathbf{y}$$

Where $\mathbf{W}$ is an $n \times n$ diagonal matrix with $\mathbf{W}_{ii} = w_i$.

Quick Recall

LWR is non-parametric: it retrains a local linear model for every query point $\mathbf{x}_q$, weighting instances by Gaussian kernel $\exp(-\|x_i - x_q\|^2 / 2\tau^2)$.

§ 5

Introduction to Regression Analysis

Regression analysis models the functional relationship between one or more independent explanatory variables (features $\mathbf{X} = [x_1, \dots, x_d]$) and a continuous numerical dependent variable (target $Y$).

Regression vs. Classification

  • Target Domain: Classification outputs discrete categorical classes ($Y \in \{0, 1\}$ or $\{C_1, \dots, C_k\}$); Regression outputs real-valued continuous numbers ($Y \in \mathbb{R}$).
  • Evaluation Metrics: Classification uses Accuracy, Precision, Recall, $F_1$, and ROC-AUC; Regression uses Mean Squared Error (MSE), Root Mean Squared Error (RMSE), Mean Absolute Error (MAE), and Coefficient of Determination ($R^2$).
Quick Recall

Regression predicts continuous numerical quantities ($Y \in \mathbb{R}$). Evaluated via Mean Squared Error (MSE) and $R^2$.

§ 6

Linear Regression: Ordinary Least Squares (OLS)

Linear regression assumes a linear relationship between features and target.

Simple Linear Regression (Single Feature)

$$y = mx + c + \epsilon$$

Ordinary Least Squares (OLS) minimizes the Residual Sum of Squares ($RSS$):

$$RSS = \sum_{i=1}^n (y_i - (m x_i + c))^2$$

Taking partial derivatives with respect to $m$ and $c$ and setting them to zero yields the closed-form solutions:

OLS Closed-Form Formulas $$m = \frac{\sum_{i=1}^n (x_i - \bar{x})(y_i - \bar{y})}{\sum_{i=1}^n (x_i - \bar{x})^2} = \frac{\text{Cov}(X, Y)}{\text{Var}(X)}$$ $$c = \bar{y} - m \bar{x}$$

Multiple Linear Regression (Matrix Normal Equation)

For $d$ features, $\hat{y} = \mathbf{X} \mathbf{w}$. The closed-form analytical solution that minimizes Mean Squared Error is the Normal Equation:

$$\mathbf{w} = (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T \mathbf{y}$$

§ 7

Polynomial Regression & Bias-Variance Tradeoff

When the relationship between features and target is non-linear (e.g., parabolic or cyclical), fitting a straight line causes severe underfitting (high bias). Polynomial Regression extends linear regression by introducing powers of features as new independent variables:

$$\hat{y} = w_0 + w_1 x + w_2 x^2 + w_3 x^3 + \dots + w_d x^d$$

Crucially, polynomial regression remains a linear model because it is linear in its parameters $\mathbf{w}$, and can be solved directly using the standard OLS Normal Equation over the transformed feature matrix $\boldsymbol{\Phi}(X)$.

The Bias-Variance Dilemma Across Polynomial Degrees

Degree ($d$)Model BehaviorBias vs. VarianceRemedy
Degree 1 (Linear)Underfitting: straight line fails to capture curvatureHigh Bias, Low VarianceIncrease polynomial degree
Degree 2–3 (Optimal)Optimal generalization: captures underlying trend without fitting noiseBalanced Bias and VarianceCross-validation model selection
Degree 15+ (Excessive)Overfitting: oscillates wildly to pass through every individual noise pointLow Bias, High VarianceRegularization ($L_2$ Ridge / $L_1$ Lasso)
Quick Recall

Polynomial regression models non-linear phenomena via $\sum w_k x^k$. It is linear in parameters. High degree polynomials cause overfitting (high variance), mitigated via Ridge/Lasso regularization.

§ 8

Logistic Regression

Despite its name, Logistic Regression is a classification algorithm used to estimate the probability that an instance belongs to a binary class ($Y \in \{0, 1\}$).

The Sigmoid (Logistic) Function

Linear regression maps input features to unbounded real values: $z = \mathbf{w}^T \mathbf{x} \in (-\infty, +\infty)$. Logistic regression passes $z$ through the Sigmoid Activation Function $\sigma(z)$ to squash outputs into valid probabilities in $(0, 1)$: $$P(Y = 1 \mid \mathbf{x}) = \sigma(z) = \frac{1}{1 + e^{-z}} = \frac{1}{1 + e^{-(\mathbf{w}^T \mathbf{x})}}$$ Properties: $\sigma(0) = 0.5$, $\sigma(z) \to 1$ as $z \to +\infty$, and $\sigma(z) \to 0$ as $z \to -\infty$.

Figure 3.2: The logistic sigmoid curve mapping the real line into calibrated probabilities.

Odds Ratio and the Logit Function

The Odds of an event is the ratio of probability of occurrence to non-occurrence: $$\text{Odds} = \frac{p}{1 - p} = e^z$$ Taking the natural logarithm yields the Logit: $$\ln\left(\frac{p}{1 - p}\right) = z = w_0 + w_1 x_1 + \dots + w_d x_d$$ Thus, logistic regression is linear in the log-odds space!

Loss Function: Binary Cross-Entropy (Log Loss)

We cannot use Mean Squared Error for logistic regression because squaring $\sigma(z)$ creates a non-convex loss surface plagued by local minima. Instead, we use Maximum Likelihood Estimation, leading to the convex Binary Cross-Entropy Loss:

$$J(\mathbf{w}) = - \frac{1}{n} \sum_{i=1}^n \Big[ y_i \ln(\hat{p}_i) + (1 - y_i) \ln(1 - \hat{p}_i) \Big]$$
Solved Problem 4 · Exam Level Logistic Classification

  1. Compute the logit value $z$ for a patient with $x_1 = 4$ cigarettes and $x_2 = 10$ BMI units above baseline.
  2. Compute the odds of developing cardiovascular disease for this patient.
  3. Compute the predicted probability $P(Y = 1 \mid \mathbf{x})$.
  4. Using a classification threshold of $0.5$, predict the diagnostic class.
Step 1: Compute Logit $z$
$$z = -3.0 + 0.5(4) + 0.2(10) = -3.0 + 2.0 + 2.0 = \mathbf{+1.0000}$$
Step 2: Compute Odds
$$\text{Odds} = e^z = e^{1.0} \approx \mathbf{2.7183}$$

The patient is approximately $2.72$ times more likely to be at risk than healthy.

Step 3: Compute Predicted Probability $\sigma(z)$
$$P(Y = 1 \mid \mathbf{x}) = \frac{1}{1 + e^{-z}} = \frac{1}{1 + e^{-1.0}} = \frac{1}{1 + 0.367879} = \frac{1}{1.367879} \approx \mathbf{0.7311} \quad (73.11\%)$$
Step 4: Classification Decision

Since $P(Y = 1 \mid \mathbf{x}) = 0.7311 \ge 0.50$, the patient is classified into Class 1 (High Risk).

Final Verified Results Logit z = +1.0000 | Odds = 2.7183 | P(Y=1) = 0.7311 (73.11%) → Classified as Positive (1)
Quick Recall

Logistic regression models probability via $\sigma(z) = \frac{1}{1 + e^{-z}}$. Linear in log-odds $\ln \frac{p}{1-p} = \mathbf{w}^T\mathbf{x}$. Optimized via Binary Cross-Entropy (Log Loss).

§ 9

Decision Tree Learning Model

A Decision Tree is a hierarchical, non-parametric model that recursively partitions the input space into axis-aligned rectangular regions.

Figure 3.3: Hierarchical structure of a Decision Tree: Root, Decision Tests, and Leaves.

Core Components and Inductive Bias

  • Root Node: The initial feature split that maximizes impurity reduction across the entire training sample.
  • Internal Nodes: Subsequent conditional decision tests evaluating a single attribute.
  • Branches: Possible outcomes of the attribute test.
  • Leaf Nodes: Terminal nodes containing the final predicted class or continuous mean value.
  • Inductive Bias: Occam's Razor: Prefer the shortest (shallowest) tree that is consistent with the training data, and place attributes with the highest information gain closest to the root.
Quick Recall

Decision trees recursively partition feature space into hyper-rectangles. Inductive bias: Occam's Razor (prefers shorter trees with high-gain attributes near the root).

§ 10

Decision Tree Induction Algorithms: ID3, C4.5 & CART

Tree induction uses a greedy top-down recursive divide-and-conquer strategy (Hunt's algorithm) guided by mathematical impurity measures:

1. Shannon Entropy and Information Gain (ID3)

Invented by Ross Quinlan. Entropy measures the impurity or disorder of a set $S$ containing instances belonging to $c$ classes:

Shannon Entropy Formula $$H(S) = - \sum_{i=1}^c p_i \log_2(p_i)$$ Where $p_i$ is the proportion of instances belonging to class $i$. For binary classification ($p_+, p_-$): $$H(S) = - p_+ \log_2(p_+) - p_- \log_2(p_-)$$ (By convention, $0 \log_2 0 = 0$). Entropy is $0.0$ for completely pure nodes (all instances same class) and reaches its maximum of $1.0$ when classes are evenly split ($50\% / 50\%$).
Information Gain (IG)

The expected reduction in entropy achieved by partitioning $S$ on attribute $A$: $$IG(S, A) = H(S) - \sum_{v \in \text{Values}(A)} \frac{|S_v|}{|S|} H(S_v)$$ ID3 selects the attribute that maximizes $IG(S, A)$ as the split node.

Solved Problem 3 · Exam Level Decision Tree Induction
A sports facility logs $n = 6$ weekend records to predict whether members play tennis ($\text{Play} \in \{\text{Yes}, \text{No}\}$):
DayOutlookTemperaturePlay Tennis
D1SunnyHotNo (-)
D2SunnyHotNo (-)
D3OvercastHotYes (+)
D4SunnyMildYes (+)
D5OvercastMildYes (+)
D6OvercastMildYes (+)
Apply the ID3 algorithm to:
  1. Calculate the overall target Entropy $H(S)$.
  2. Calculate the Information Gain $IG(S, \text{Outlook})$.
  3. Calculate the Information Gain $IG(S, \text{Temperature})$.
  4. Determine which attribute is selected as the Root Node.
Step 1: Compute Overall Target Entropy $H(S)$

Total instances: $|S| = 6$. Target breakdown: $4 \text{ Yes } (+), \; 2 \text{ No } (-)$.

$$p_+ = \frac{4}{6} = \frac{2}{3} \approx 0.6667, \quad p_- = \frac{2}{6} = \frac{1}{3} \approx 0.3333$$ $$H(S) = - \left( \frac{2}{3} \log_2 \frac{2}{3} + \frac{1}{3} \log_2 \frac{1}{3} \right) = - \big( 0.6667 \times (-0.5850) + 0.3333 \times (-1.5850) \big)$$ $$H(S) = - (-0.3900 - 0.5283) = \mathbf{0.9183}$$
Step 2: Evaluate Attribute "Outlook"

Values: $\{\text{Sunny}, \text{Overcast}\}$.

  • $S_{\text{Sunny}}$ ($3$ instances: D1, D2, D4): $1 \text{ Yes}, 2 \text{ No}$. $$H(S_{\text{Sunny}}) = - \left( \frac{1}{3} \log_2 \frac{1}{3} + \frac{2}{3} \log_2 \frac{2}{3} \right) = \mathbf{0.9183}$$
  • $S_{\text{Overcast}}$ ($3$ instances: D3, D5, D6): $3 \text{ Yes}, 0 \text{ No}$ (Completely pure!). $$H(S_{\text{Overcast}}) = - \left( \frac{3}{3} \log_2 \frac{3}{3} + 0 \right) = - (1 \times 0) = \mathbf{0.0000}$$

Compute weighted average entropy:

$$H(S \mid \text{Outlook}) = \frac{3}{6} H(S_{\text{Sunny}}) + \frac{3}{6} H(S_{\text{Overcast}}) = \frac{1}{2}(0.9183) + \frac{1}{2}(0.0) = \mathbf{0.45915}$$ $$IG(S, \text{Outlook}) = H(S) - H(S \mid \text{Outlook}) = 0.9183 - 0.45915 = \mathbf{0.45915}$$
Step 3: Evaluate Attribute "Temperature"

2. C4.5: Gain Ratio

ID3 is strongly biased towards attributes with large numbers of distinct values (e.g., a "Customer ID" or "Date" attribute with $n$ distinct values achieves $IG = H(S)$ because each split has size 1 and entropy 0, but provides zero generalization).

Quinlan's C4.5 algorithm penalizes broad multi-way splits using Gain Ratio:

$$\text{Gain Ratio}(S, A) = \frac{IG(S, A)}{\text{Split Information}(S, A)}$$ $$\text{Split Information}(S, A) = - \sum_{v \in \text{Values}(A)} \frac{|S_v|}{|S|} \log_2 \left( \frac{|S_v|}{|S|} \right)$$

3. CART: Gini Impurity

Breiman's CART (Classification and Regression Trees) constructs binary trees using Gini Impurity instead of logarithmic entropy (faster to compute):

$$\text{Gini}(S) = 1 - \sum_{i=1}^c p_i^2$$

For binary classes: $\text{Gini}(S) = 1 - (p_+^2 + p_-^2) = 2 p_+ p_-$. Pure node $\implies \text{Gini} = 0.0$; maximum impurity $\implies \text{Gini} = 0.5$.

Tree Pruning Strategies

  • Pre-Pruning (Early Stopping): Halts tree growth before complete fitting if node sample size falls below threshold $N_{\min}$, tree depth reaches $D_{\max}$, or $IG$ falls below threshold $\theta$. Prone to underfitting.
  • Post-Pruning: Grows the full, unconstrained tree to zero training error, then recursively removes leaves/subtrees that fail to improve performance on a separate validation set (Reduced Error Pruning / Cost-Complexity Pruning). Superior generalization.
Quick Recall

ID3 uses Entropy and Information Gain. C4.5 uses Gain Ratio to penalize broad splits. CART uses Gini Impurity $1 - \sum p_i^2$. Post-pruning prevents overfitting.

Important Exam Questions

Curated questions structured according to VTU and RIT examination standards.

2-Mark Questions

Q1. Why is K-NN called a lazy learner?
$K$-NN is called a lazy learner because it performs zero generalization or computation during the training phase. It simply stores the training instances in memory and delays all distance computations and decision making until a query point is presented during inference.
Q2. Define the Sigmoid function and state its range.
The Sigmoid function is an S-shaped activation function defined as: $$\sigma(z) = \frac{1}{1 + e^{-z}}$$ It squashes real-valued inputs from $(-\infty, +\infty)$ into valid probability values strictly in the range $(0, 1)$.
Q3. Define Gini Impurity as used in CART.
Gini Impurity measures the probability that a randomly chosen element from a dataset would be incorrectly labeled if it were randomly labeled according to the class distribution: $$\text{Gini}(S) = 1 - \sum_{i=1}^c p_i^2$$

5-Mark Questions

Q4. Explain why C4.5 uses Gain Ratio instead of Information Gain.
ID3's Information Gain has a severe bias towards attributes with many distinct values (such as an individual transaction ID or date). When an attribute has unique values for every instance, partitioning on it splits the dataset into subsets of size 1 with zero entropy, achieving maximum possible Information Gain ($H(S)$), but yielding zero predictive power on unseen data.

C4.5 resolves this flaw by normalizing Information Gain by the Split Information: $$\text{Gain Ratio}(S, A) = \frac{IG(S, A)}{- \sum \frac{|S_v|}{|S|} \log_2 \frac{|S_v|}{|S|}}$$ Split Information acts as a penalty that grows with the number and uniformity of partitions, discouraging trivial high-cardinality splits.
Q5. Describe the Nearest Centroid Classifier and discuss its advantages and limitations.
Mechanism: Computes the mean prototype vector $\boldsymbol{\mu}_c$ for each class during training. A query point is assigned to the class with the closest centroid under Euclidean distance.
Advantages: Ultra-fast inference ($O(C \times d)$), low storage ($O(C \times d)$), and resilient to local noise.
Limitations: Generates only linear decision boundaries, assuming classes are spherical and linearly separable. Completely misclassifies non-convex, multimodal, or concentric ring distributions.

10-Mark Questions

Q6. Derive the Ordinary Least Squares (OLS) closed-form formulas for slope m and intercept c in simple linear regression.
Objective: Minimize the sum of squared errors: $$E(m, c) = \sum_{i=1}^n (y_i - (m x_i + c))^2$$ Step 1: Partial derivative with respect to c: $$\frac{\partial E}{\partial c} = -2 \sum_{i=1}^n (y_i - m x_i - c) = 0 \implies \sum y_i - m \sum x_i - n c = 0$$ Dividing by $n$: $$\bar{y} - m \bar{x} - c = 0 \implies \mathbf{c = \bar{y} - m \bar{x}}$$ Step 2: Partial derivative with respect to m: $$\frac{\partial E}{\partial m} = -2 \sum_{i=1}^n x_i (y_i - m x_i - c) = 0 \implies \sum x_i y_i - m \sum x_i^2 - c \sum x_i = 0$$ Substitute $c = \bar{y} - m \bar{x}$: $$\sum x_i y_i - m \sum x_i^2 - (\bar{y} - m \bar{x}) \sum x_i = 0$$ $$\sum x_i y_i - \bar{y} \sum x_i = m \left( \sum x_i^2 - \bar{x} \sum x_i \right)$$ Using algebraic identities $\sum x_i y_i - n \bar{x} \bar{y} = \sum (x_i - \bar{x})(y_i - \bar{y})$ and $\sum x_i^2 - n \bar{x}^2 = \sum (x_i - \bar{x})^2$: $$\mathbf{m = \frac{\sum_{i=1}^n (x_i - \bar{x})(y_i - \bar{y})}{\sum_{i=1}^n (x_i - \bar{x})^2}}$$

"Consider the dataset of 10 samples for predicting whether to Play Tennis. Compute information gain of attribute outlook using ID3 algorithm."

Step 1: Compute Total Entropy $H(S)$ of the 10-instance dataset ($6 \text{ Yes}, 4 \text{ No}$):

$$H(S) = -\left(\frac{6}{10}\right)\log_2\left(\frac{6}{10}\right) - \left(\frac{4}{10}\right)\log_2\left(\frac{4}{10}\right) = -0.6(-0.73697) - 0.4(-1.32193) = 0.44218 + 0.52877 = \mathbf{0.97095 \text{ bits}}$$

Step 2: Partition by Attribute $\text{Outlook} \in \{\text{Sunny}, \text{Overcast}, \text{Rain}\}$:

  • Sunny (4 instances: 1 Yes, 3 No): $$H(S_{\text{Sunny}}) = -\frac{1}{4}\log_2\left(\frac{1}{4}\right) - \frac{3}{4}\log_2\left(\frac{3}{4}\right) = 0.50000 + 0.31128 = \mathbf{0.81128 \text{ bits}}$$
  • Overcast (2 instances: 2 Yes, 0 No): Completely pure subset: $$H(S_{\text{Overcast}}) = \mathbf{0.00000 \text{ bits}}$$
  • Rain (4 instances: 3 Yes, 1 No): $$H(S_{\text{Rain}}) = -\frac{3}{4}\log_2\left(\frac{3}{4}\right) - \frac{1}{4}\log_2\left(\frac{1}{4}\right) = 0.31128 + 0.50000 = \mathbf{0.81128 \text{ bits}}$$

Step 3: Remainder / Expected Child Entropy:

$$\text{Remainder}(S, \text{Outlook}) = \sum_{v} \frac{|S_v|}{|S|} H(S_v) = \frac{4}{10}(0.81128) + \frac{2}{10}(0) + \frac{4}{10}(0.81128) = \frac{8}{10}(0.81128) = \mathbf{0.64902 \text{ bits}}$$

Step 4: Information Gain:

$$\mathbf{IG(S, \text{Outlook}) = H(S) - \text{Remainder}(S, \text{Outlook}) = 0.97095 - 0.64902 = \mathbf{0.32193 \text{ bits}}}$$

Ramaiah Internal Assessment - II (May 2026) • Q 1(a) [3 Marks • Blooms L2, CO3]

"Explain the working of the CART algorithm."

Classification and Regression Trees (CART), developed by Breiman et al., constructs strictly binary trees (every non-leaf node has exactly two children):

  • 1. Splitting Criterion (Gini Impurity for Classification): $$\text{Gini}(S) = 1 - \sum_{i=1}^C p_i^2$$ For a binary split candidate dividing $S$ into subsets $S_L$ and $S_R$, CART selects the split maximizing the reduction in impurity: $$\Delta \text{Gini}(S, A) = \text{Gini}(S) - \left( \frac{|S_L|}{|S|}\text{Gini}(S_L) + \frac{|S_R|}{|S|}\text{Gini}(S_R) \right)$$
  • 2. Splitting for Regression Trees: Uses Mean Squared Error (variance reduction): $\sum_{x \in S_L}(y_i - \bar{y}_L)^2 + \sum_{x \in S_R}(y_i - \bar{y}_R)^2$.
  • 3. Cost-Complexity Pruning: Minimizes cost function $R_\alpha(T) = R(T) + \alpha |T|$ where $R(T)$ is misclassification rate, $|T|$ is number of terminal nodes, and $\alpha$ is penalty parameter tuned via cross-validation.

Ramaiah SEE Examination (June/July 2026) • Q 5(a) [8 Marks • Blooms L3, CO3]

"Compare simple linear regression and multiple linear regression with suitable examples. Using the housing dataset (Size, Bedrooms, Age, House Price), formulate a multiple linear regression equation to predict house price."

  • Simple Linear Regression: Models the relationship between one scalar predictor $x$ and scalar target $y$: $$y = w_0 + w_1 x + \epsilon$$ Example: Predicting house price based solely on floor area ($x_1$).
  • Multiple Linear Regression: Models the relationship between $p$ multiple independent variables $\mathbf{x} = [x_1, x_2, \dots, x_p]^T$ and scalar target $y$: $$y = w_0 + w_1 x_1 + w_2 x_2 + \dots + w_p x_p + \epsilon = \mathbf{w}^T \mathbf{x} + \epsilon$$
  • Housing Price Multiple Regression Equation Formulation: $$\mathbf{\widehat{\text{Price}} = w_0 + w_1 (\text{Size}) + w_2 (\text{Bedrooms}) + w_3 (\text{Age})}$$ Where $\mathbf{w} = [w_0, w_1, w_2, w_3]^T$ is solved via the closed-form normal equations: $$\mathbf{w} = (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T \mathbf{y}$$
