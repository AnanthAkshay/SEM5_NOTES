§ 1

Introduction to Regression Analysis

Regression analysis models the functional relationship between one or more independent explanatory variables (features $\mathbf{X} = [x_1, \dots, x_d]$) and a continuous numerical dependent variable (target $Y$).

Regression vs. Classification

  • Target Domain: Classification outputs discrete categorical classes ($Y \in \{0, 1\}$ or $\{C_1, \dots, C_k\}$); Regression outputs real-valued continuous numbers ($Y \in \mathbb{R}$).
  • Evaluation Metrics: Classification uses Accuracy, Precision, Recall, $F_1$, and ROC-AUC; Regression uses Mean Squared Error (MSE), Root Mean Squared Error (RMSE), Mean Absolute Error (MAE), and Coefficient of Determination ($R^2$).
Quick Recall

Regression predicts continuous numerical quantities ($Y \in \mathbb{R}$). Evaluated via Mean Squared Error (MSE) and $R^2$.

§ 2

Linear Regression: Ordinary Least Squares (OLS)

Linear regression assumes a linear relationship between features and target.

Simple Linear Regression (Single Feature)

$$y = mx + c + \epsilon$$

Ordinary Least Squares (OLS) minimizes the Residual Sum of Squares ($RSS$):

$$RSS = \sum_{i=1}^n (y_i - (m x_i + c))^2$$

Taking partial derivatives with respect to $m$ and $c$ and setting them to zero yields the closed-form solutions:

OLS Closed-Form Formulas $$m = \frac{\sum_{i=1}^n (x_i - \bar{x})(y_i - \bar{y})}{\sum_{i=1}^n (x_i - \bar{x})^2} = \frac{\text{Cov}(X, Y)}{\text{Var}(X)}$$ $$c = \bar{y} - m \bar{x}$$

Multiple Linear Regression (Matrix Normal Equation)

For $d$ features, $\hat{y} = \mathbf{X} \mathbf{w}$. The closed-form analytical solution that minimizes Mean Squared Error is the Normal Equation:

$$\mathbf{w} = (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T \mathbf{y}$$

§ 3

Multiple Linear Regression & Normal Equations

When a continuous outcome $y$ depends on multiple predictors $x_1, x_2, \dots, x_p$, Multiple Linear Regression generalizes simple OLS into matrix algebra.

Matrix Formulation of Multiple Regression

For $n$ observations and $p$ features, the model is: $$\mathbf{y} = \mathbf{X} oldsymbol{eta} + oldsymbol{\epsilon}$$ where $\mathbf{y} \in \mathbb{R}^{n imes 1}$, design matrix $\mathbf{X} \in \mathbb{R}^{n imes (p+1)}$ (with leading column of 1s for intercept), coefficient vector $oldsymbol{eta} \in \mathbb{R}^{(p+1) imes 1}$, and residuals $oldsymbol{\epsilon} \in \mathbb{R}^{n imes 1}$.

The Normal Equations (Closed-Form Analytical Solution)

Minimizing the sum of squared errors $S(oldsymbol{eta}) = (\mathbf{y} - \mathbf{X}oldsymbol{eta})^T (\mathbf{y} - \mathbf{X}oldsymbol{eta})$ by setting the gradient $ abla_{oldsymbol{eta}} S = \mathbf{0}$ yields the classic Normal Equations:

$$\mathbf{X}^T \mathbf{X} oldsymbol{eta} = \mathbf{X}^T \mathbf{y} \implies oldsymbol{eta} = (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T \mathbf{y}$$
Assumption & Invertibility

For $(\mathbf{X}^T \mathbf{X})^{-1}$ to exist, matrix $\mathbf{X}$ must have full column rank ($p+1$). If features are linearly dependent (exact multicollinearity), $(\mathbf{X}^T \mathbf{X})$ becomes singular and cannot be inverted without regularization (Ridge regression).

§ 4

Polynomial Regression & Bias-Variance Tradeoff

When the relationship between features and target is non-linear (e.g., parabolic or cyclical), fitting a straight line causes severe underfitting (high bias). Polynomial Regression extends linear regression by introducing powers of features as new independent variables:

$$\hat{y} = w_0 + w_1 x + w_2 x^2 + w_3 x^3 + \dots + w_d x^d$$

Crucially, polynomial regression remains a linear model because it is linear in its parameters $\mathbf{w}$, and can be solved directly using the standard OLS Normal Equation over the transformed feature matrix $\boldsymbol{\Phi}(X)$.

The Bias-Variance Dilemma Across Polynomial Degrees

Degree ($d$)Model BehaviorBias vs. VarianceRemedy
Degree 1 (Linear)Underfitting: straight line fails to capture curvatureHigh Bias, Low VarianceIncrease polynomial degree
Degree 2–3 (Optimal)Optimal generalization: captures underlying trend without fitting noiseBalanced Bias and VarianceCross-validation model selection
Degree 15+ (Excessive)Overfitting: oscillates wildly to pass through every individual noise pointLow Bias, High VarianceRegularization ($L_2$ Ridge / $L_1$ Lasso)
Quick Recall

Polynomial regression models non-linear phenomena via $\sum w_k x^k$. It is linear in parameters. High degree polynomials cause overfitting (high variance), mitigated via Ridge/Lasso regularization.

In Ridge regression, increasing $\lambda$ increases bias but dramatically reduces model variance. For $\lambda = 0$, Ridge reverts to standard OLS. As $\lambda o \infty$, all $eta_j o 0$, predicting the horizontal mean $ar{Y}$.

§ 6

Gradient Descent Optimization for Regression

When the number of features $p$ is large (e.g. $p > 10,000$), computing the analytical matrix inverse $(\mathbf{X}^T\mathbf{X})^{-1}$ with time complexity $O(p^3)$ is computationally prohibitive. Gradient Descent provides an iterative optimization alternative.

Batch, Stochastic, and Mini-Batch Gradient Descent

  • Batch Gradient Descent: Computes the gradient of MSE over the entire dataset $n$ at each step. Convergence is smooth and monotonic, but slow for large datasets.
  • Stochastic Gradient Descent (SGD): Computes the gradient using a single random training sample at each step. Fast updates with noisy trajectory; can escape shallow local minima.
  • Mini-Batch Gradient Descent: Computes the gradient over a small subset (e.g. $B = 32, 64, 128$). Combines the stability of batch descent with hardware vectorization speedups (GPU/SIMD).

Update Rule: $oldsymbol{eta}^{(t+1)} = oldsymbol{eta}^{(t)} - lpha abla_{oldsymbol{eta}} J(oldsymbol{eta})$, where $lpha$ is the learning rate hyperparameter.

§ 7

Logistic Regression

Despite its name, Logistic Regression is a classification algorithm used to estimate the probability that an instance belongs to a binary class ($Y \in \{0, 1\}$).

The Sigmoid (Logistic) Function

Linear regression maps input features to unbounded real values: $z = \mathbf{w}^T \mathbf{x} \in (-\infty, +\infty)$. Logistic regression passes $z$ through the Sigmoid Activation Function $\sigma(z)$ to squash outputs into valid probabilities in $(0, 1)$: $$P(Y = 1 \mid \mathbf{x}) = \sigma(z) = \frac{1}{1 + e^{-z}} = \frac{1}{1 + e^{-(\mathbf{w}^T \mathbf{x})}}$$ Properties: $\sigma(0) = 0.5$, $\sigma(z) \to 1$ as $z \to +\infty$, and $\sigma(z) \to 0$ as $z \to -\infty$.

Figure 3.2: The logistic sigmoid curve mapping the real line into calibrated probabilities.

Odds Ratio and the Logit Function

The Odds of an event is the ratio of probability of occurrence to non-occurrence: $$\text{Odds} = \frac{p}{1 - p} = e^z$$ Taking the natural logarithm yields the Logit: $$\ln\left(\frac{p}{1 - p}\right) = z = w_0 + w_1 x_1 + \dots + w_d x_d$$ Thus, logistic regression is linear in the log-odds space!

Loss Function: Binary Cross-Entropy (Log Loss)

We cannot use Mean Squared Error for logistic regression because squaring $\sigma(z)$ creates a non-convex loss surface plagued by local minima. Instead, we use Maximum Likelihood Estimation, leading to the convex Binary Cross-Entropy Loss:

$$J(\mathbf{w}) = - \frac{1}{n} \sum_{i=1}^n \Big[ y_i \ln(\hat{p}_i) + (1 - y_i) \ln(1 - \hat{p}_i) \Big]$$

Logistic regression models probability via $\sigma(z) = \frac{1}{1 + e^{-z}}$. Linear in log-odds $\ln \frac{p}{1-p} = \mathbf{w}^T\mathbf{x}$. Optimized via Binary Cross-Entropy (Log Loss).

Important Examination Questions (Regression)

Curated questions structured according to VTU and Ramaiah examination standards.

2-Mark / 3-Mark Questions

Q1. Differentiate between Linear Regression and Logistic Regression.
Linear Regression: Models continuous numerical targets $y \in \mathbb{R}$ using unbounded linear hypotheses $\hat{y} = \mathbf{w}^T\mathbf{x} + b$, evaluated via MSE.
Logistic Regression: Models categorical class probabilities $P(y=1|\mathbf{x}) \in (0, 1)$ using the non-linear Sigmoid activation function, evaluated via Binary Cross-Entropy (Log-Loss).
Q2. Define the Sigmoid function and state its range and mathematical derivative.
The Sigmoid activation function is defined as $\sigma(z) = rac{1}{1 + e^{-z}}$. It squashes any real-valued input from $(-\infty, +\infty)$ into the probability range $(0, 1)$. Its derivative is computationally efficient: $\sigma'(z) = \sigma(z)(1 - \sigma(z))$.
Q3. Why is Adjusted R² preferred over standard R² in Multiple Regression?
Standard $R^2$ mechanically increases or remains constant whenever a new predictor is added to a model, even if the feature is useless random noise. Adjusted $R^2$ introduces a degrees-of-freedom penalty for every additional parameter added: $R^2_{ ext{adj}} = 1 - \left[ rac{(1 - R^2)(n - 1)}{n - p - 1} ight]$, ensuring it increases only if the new feature genuinely improves predictive accuracy.

5-Mark / 6-Mark Questions

Q4. Compare Ridge Regression (L2) and Lasso Regression (L1) with their loss functions and properties.
Ridge Regression: Adds an $L_2$ squared penalty $\lambda \sum eta_j^2$. Has closed-form solution $oldsymbol{eta} = (\mathbf{X}^T\mathbf{X} + \lambda\mathbf{I})^{-1}\mathbf{X}^T\mathbf{y}$. Shrinks coefficients smoothly toward zero but never forces them to exact zero.

Lasso Regression: Adds an $L_1$ absolute value penalty $\lambda \sum |eta_j|$. Due to the sharp corners of the $L_1$ constraint diamond, it forces irrelevant coefficients to become identically zero, performing automatic embedded feature selection.
Q5. Explain the concept of Odds Ratio and Log-Odds (Logit function) in Logistic Regression.
Odds: The ratio of probability of occurrence to probability of non-occurrence: $ ext{Odds} = rac{p}{1-p} = e^z$.
Logit: Taking the natural logarithm of odds yields the logit function: $ ext{Logit}(p) = \ln\left( rac{p}{1-p} ight) = z = \mathbf{w}^T\mathbf{x} + b$.
This shows that Logistic Regression is a generalized linear model that assumes the log-odds of the positive class are a linear combination of the input predictors.

8-Mark / 10-Mark Questions

Q6. Derive the Ordinary Least Squares (OLS) closed-form formulas for slope b1 and intercept b0 in simple linear regression.
Objective: Minimize the Sum of Squared Residuals: $S(eta_0, eta_1) = \sum_{i=1}^n (y_i - (eta_0 + eta_1 x_i))^2$.

1. Partial derivative with respect to $eta_0$:
$ rac{\partial S}{\partial eta_0} = -2 \sum (y_i - eta_0 - eta_1 x_i) = 0 \implies \sum y_i - n eta_0 - eta_1 \sum x_i = 0$
Dividing by $n$: $ar{y} - eta_0 - eta_1 ar{x} = 0 \implies \mathbf{eta_0 = ar{y} - eta_1 ar{x}}$.

2. Partial derivative with respect to $eta_1$:
$ rac{\partial S}{\partial eta_1} = -2 \sum x_i (y_i - eta_0 - eta_1 x_i) = 0 \implies \sum x_i y_i - eta_0 \sum x_i - eta_1 \sum x_i^2 = 0$
Substitute $eta_0 = ar{y} - eta_1 ar{x}$:
$\sum x_i y_i - (ar{y} - eta_1 ar{x})\sum x_i - eta_1 \sum x_i^2 = 0 \implies \sum x_i y_i - ar{y}\sum x_i = eta_1 \left( \sum x_i^2 - ar{x}\sum x_i ight)$
Using algebraic identities $\sum x_i y_i - nar{x}ar{y} = \sum (x_i - ar{x})(y_i - ar{y})$ and $\sum x_i^2 - nar{x}^2 = \sum (x_i - ar{x})^2$:
$$\mathbf{eta_1 = rac{\sum_{i=1}^n (x_i - ar{x})(y_i - ar{y})}{\sum_{i=1}^n (x_i - ar{x})^2} = rac{n \sum x_i y_i - (\sum x_i)(\sum y_i)}{n \sum x_i^2 - (\sum x_i)^2}}$$

"Differentiate Logistic Regression and Linear Regression in machine learning."

1. Output Target: Linear Regression predicts continuous numeric quantities $y \in (-\infty, +\infty)$, whereas Logistic Regression predicts discrete probabilities $P(y=1|\mathbf{x}) \in (0, 1)$ mapped to class labels $\{0, 1\}$.

2. Hypothesis Function: Linear regression uses $\hat{y} = \mathbf{w}^T\mathbf{x} + b$; logistic regression wraps the linear score inside the Sigmoid function $\sigma(z) = 1/(1+e^{-z})$.

3. Loss Function: Linear regression minimizes Mean Squared Error (MSE), whereas logistic regression minimizes Binary Cross-Entropy (Log-Loss) because MSE is non-convex when combined with the sigmoid activation function.

Problem 1: Simple Linear Regression • Ice Cream Sales vs Temperature Easy • Verified Formula

A shop records daily temperature (°C) and corresponding ice cream sales (units) for 8 days: $X = [20, 22, 24, 26, 28, 30, 32, 34]$, $Y = [120, 135, 150, 165, 180, 195, 210, 225]$. 1. Find the regression equation. 2. Predict sales when temperature is 29°C.

Summations ($n=8$): $\sum X = 216 \implies ar{X} = 27.00$, $\sum Y = 1380 \implies ar{Y} = 172.50$, $\sum X^2 = 6000$, $\sum XY = 38520$.

Intercept: $a = 172.50 - (7.5000)(27.00) = 172.50 - 202.50 = \mathbf{-30.0000}$.

Problem 2: Regularization • Ridge vs OLS Coefficient Shrinkage Moderate • Verified Matrix Math

Given centered 1D feature data where $\sum x_i^2 = 100$ and $\sum x_i y_i = 400$. Calculate the OLS slope and the Ridge slope for regularization penalty $\lambda = 20$.

OLS Slope: $eta_{ ext{OLS}} = rac{\sum x_i y_i}{\sum x_i^2} = rac{400}{100} = \mathbf{4.0000}$.

Ridge Slope ($\lambda = 20$): $eta_{ ext{Ridge}} = rac{\sum x_i y_i}{\sum x_i^2 + \lambda} = rac{400}{100 + 20} = rac{400}{120} = \mathbf{3.3333}$.

Conclusion: The Ridge penalty successfully shrunk the coefficient from $4.00$ to $3.33$ (a 16.7% shrinkage), dampening sensitivity to potential noise in the feature.
