What is AI? The Four Historical Approaches

§ 1

Historically, researchers have approached Artificial Intelligence along two fundamental dimensions: whether the goal is to match human performance or adhere to an ideal standard of rationality, and whether the focus is on internal thought processes or external behavior (actions).

Focus Dimension Human-Centric Approach Rationality-Centric (Ideal Standard)
Thinking (Mind / Reasoning) 1. Thinking Humanly (Cognitive Modeling)
Requires determining how humans think through psychological experiments, brain scans (fMRI), or introspective analysis. Compares computer traces to human cognitive behavior. 		2. Thinking Rationally (Laws of Thought)
Rooted in Aristotle's syllogisms and formal mathematical logic. Focuses on irrefutable reasoning patterns (P  ⟹  Q,P⊢QP \implies Q, P \vdash QP⟹Q,P⊢Q). Limited by computational tractability and expressing informal uncertain knowledge.
Acting (Behavior / Output) 3. Acting Humanly (The Turing Test)
Proposed by Alan Turing (1950). An agent passes if a human interrogator cannot distinguish its conversational replies from those of a human. Requires NLP, knowledge representation, automated reasoning, and machine learning. 		4. Acting Rationally (The Rational Agent) — MODERN STANDARD
A rational agent is one that acts so as to achieve the best expected outcome, or best expected utility when uncertainty is present. Correct inference is one way to act rationally, but reflexive safety actions are also rational.
WHY MODERN AI FOCUSES ON THE RATIONAL AGENT APPROACH:

The rational agent approach is superior to human modeling for two main reasons:

  1. It is more general than the "laws of thought" approach, because correct inference is only one of several mechanisms for achieving rationality (e.g. reflex actions can be rational without logical deduction).
  2. It is more mathematically amenable to scientific development than approaches based on human behavior, because the standard of rationality is mathematically well-defined and completely independent of human biological quirks and cognitive errors.

The Concept of Rationality and Autonomy

§ 3

What is rational at any given time depends on four factors: the performance measure that defines the criterion of success, the agent's prior knowledge of the environment, the actions that the agent can perform, and the agent's percept sequence to date.

DEFINITION OF A RATIONAL AGENT:

For each possible percept sequence, a rational agent should select an action that is expected to maximize its performance measure, given the evidence provided by the percept sequence and whatever built-in knowledge the agent has.

Critical Distinctions in Rationality

Concept Key Definition Crucial Exam Contrast
Omniscience vs Rationality An omniscient agent knows the actual outcome of its actions and can act accordingly. Omniscience is impossible in reality. Rationality maximizes expected performance based on available information, not actual outcome (e.g. looking both ways before crossing a street is rational, even if a meteorite strikes).
Information Gathering & Exploration Doing actions to modify future percepts (e.g. looking around, medical tests). A rational agent must gather information and explore unfamiliar environments rather than blindly acting on initial assumptions.
Autonomy An agent is autonomous to the extent that its behavior is determined by its own experience (learning), rather than solely by the initial knowledge programmed by its designer. A non-autonomous agent relies entirely on pre-baked assumptions and fails when the environment changes. Truly rational agents learn to become autonomous over time.

Internal Agent Architectures

§ 6

Russell and Norvig define five basic agent architectures of increasing sophistication: Simple Reflex, Model-Based Reflex, Goal-Based, Utility-Based, and Learning Agents.

AI-assisted study notes - verify with your textbook and faculty notes. Page 9 of 28
ISE552 · Unit 1 Internal Agent Architectures
Agent Architecture Internal State & Mechanism Action Selection Rule Limitation / Failure Mode
1. Simple Reflex Agent No memory of past percepts. Direct link from current percept to action. Condition-Action Rules:
if condition then action		 Infinite loops in partially observable environments (e.g. can't escape if state looks identical).
2. Model-Based Reflex Agent Maintains an internal state tracking aspects of the unobserved world. Updates state using transition model ("How world evolves") and sensor model ("How actions affect world"). Lacks explicit future goals; only acts on current beliefs.
3. Goal-Based Agent Combines internal state with explicit Goal information describing desirable situations. Uses Search and Planning to find sequences of actions that achieve the goal. Binary satisfaction (goal achieved vs not); cannot trade off between conflicting goals.
4. Utility-Based Agent Uses an explicit Utility function mapping states to real numbers (degrees of happiness). Selects the action that maximizes Expected Utility. Computationally expensive; designing complex multi-attribute utility functions is hard.
5. Learning Agent Divided into 4 functional modules: Critic, Learning Element, Performance Element, Problem Generator. Learns from feedback to improve performance beyond initial programming. Requires training samples and exploration-exploitation balance.

Formal State-Space Formulation of the 8-Puzzle

The 8-puzzle consists of a 3×33 \times 33×3 board with 8 numbered sliding tiles and one blank space.

1. Formal 5-Component Specification:

  • States: A specification of the position of each of the 8 numbered tiles and the blank square in the 3×33 \times 33×3 grid.
  • Initial State: Any valid configuration of the board.
  • Actions: Movements of the blank space: {Left,Right,Up,Down}\{\text{Left}, \text{Right}, \text{Up}, \text{Down}\}{Left,Right,Up,Down}. (Moving the blank is cleaner than moving individual tiles!).
  • Transition Model: Given state sss and blank move aaa, returns the resulting board with the blank and adjacent tile swapped.
  • Goal Test: Matches the designated goal configuration (e.g. tiles ordered 1 to 8 with blank at bottom-right or center).
  • Path Cost: Each step costs 1 (path cost = number of moves).

2. State Space Size & Inversion Parity Analysis:

  • Total distinct arrangements of 9 squares =9!=362,880 states= 9! = \mathbf{362,880\text{ states}}=9!=362,880 states.
  • Inversion Parity Theorem: The state space is partitioned into two disjoint graph components of size 9!/2=181,4409! / 2 = 181,4409!/2=181,440 states each. Any legal slide move preserves the even/odd parity of the number of tile inversions. Exactly half the states can reach the goal; the other half are provably impossible!

3. Branching Factor:

  • Blank in corner (4 corners): 2 legal moves.
  • Blank on edge (4 edges): 3 legal moves.
  • Blank in center (1 center): 4 legal moves.
  • Average branching factor: b=4(2)+4(3)+1(4)9=8+12+49=249≈2.67b = \frac{4(2) + 4(3) + 1(4)}{9} = \frac{8 + 12 + 4}{9} = \frac{24}{9} \approx \mathbf{2.67}b=94(2)+4(3)+1(4)​=98+12+4​=924​≈2.67.

"Explain Model-Based Reflex Agent with a neat schematic diagram and algorithmic flow."

📝 Practice Problem:
Show Complete Step-by-Step Model Answer
Solution:

1. Architectural Purpose & Motivation:

A Simple Reflex Agent fails whenever the task environment is partially observable, because multiple distinct world states can generate identical sensory percepts, causing the agent to fall into infinite loops. A Model-Based Reflex Agent overcomes this limitation by maintaining an internal state that tracks aspects of the world currently unobservable by sensors.

2. Two Core Internal Knowledge Models:

  • Transition Model ("How the world evolves"): Knowledge of the physical dynamics of the environment independent of the agent (e.g., if a car is moving ahead, it will continue moving forward in the next time step).
  • Sensor / Effect Model ("What my actions do"): Knowledge of how the agent's own actions affect the state of the world (e.g., turning the steering wheel left causes the vehicle to rotate counter-clockwise).

3. Algorithmic Flow & Pseudocode:

function MODEL-BASED-REFLEX-AGENT(percept) returns an action
  persistent: state, the agent's current conception of the world state
              model, a description of how the next state depends on current state and action
              rules, a set of condition-action rules
              action, the most recent action, initially none

  state ← UPDATE-STATE(state, action, percept, model)
  rule ← RULE-MATCH(state, rules)
  action ← rule.ACTION
  return action

4. Operational Trace:

  1. Sensors receive current percept ptp_tpt​.
  2. UPDATE-STATE combines previous state st−1s_{t-1}st−1​, previous action at−1a_{t-1}at−1​, current percept ptp_tpt​, and world physics model to synthesize new belief state sts_tst​.
  3. Condition-action rules evaluate against the comprehensive belief state sts_tst​ rather than raw sensor inputs.
  4. Selected action ata_tat​ is dispatched to actuators, and saved into memory for the next cycle.

PRACTICE 6 • RATIONALITY VS OMNISCIENCE SCENARIO

An autonomous vehicle travels safely at 40 km/h on an empty road. A boulder suddenly dislodges from an unmonitored cliff face and crushes the car. Was the vehicle agent irrational? Explain.

📝 Practice Problem:
Show Step-by-Step Solution
Solution:

Answer: No, the agent was completely rational!

Engineering Justification:

  • An omniscient agent knows the actual future outcome of its actions with supernatural precision. An omniscient car would have stopped before the cliff because it "knew" the boulder would fall. However, omniscience is physically impossible in real-world stochastic environments.
  • A rational agent maximizes expected performance based on its built-in knowledge, sensory percepts, and past experience. Traveling at the legal speed limit of 40 km/h with no prior percept of overhead cliff instability is the action that maximizes expected utility.
  • Rationality is judged on the quality of decision-making given available information ex-ante, whereas perfection in hindsight is the criterion of omniscience. Therefore, an unexpected catastrophic event does not imply irrationality.
