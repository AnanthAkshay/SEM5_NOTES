Games as Adversarial Search Problems

§ 1

In a multi-agent competitive environment, the actions of other agents directly oppose our goals. In AI, these are formalized as adversarial search problems, commonly referred to as games.

6 SIX COMPONENTS OF A FORMAL GAME DEFINITION
  1. Initial State (s0s_0s0​): The board configuration and specification of which player moves first.
  2. Player(s)Player(s)Player(s) Returns: The player whose turn it is to move in state sss (e.g. MAXMAXMAX or MINMINMIN).
  3. Actions(s)Actions(s)Actions(s) Returns: The set of legal moves permissible in state sss.
  4. Transition Model Result(s,a)Result(s, a)Result(s,a): Returns the state resulting from taking action aaa in state sss.
  5. Terminal Test TerminalTest(s)TerminalTest(s)TerminalTest(s): True if the game has ended (win, loss, or draw); False otherwise. States where the game has ended are called terminal states.
  6. Utility Function Utility(s,p)Utility(s, p)Utility(s,p): (Also called objective function or payoff function). Assigns a numerical value to terminal state sss for player ppp. In chess: +1+1+1 for win, 000 for draw, −1-1−1 for loss.

Zero-Sum Games: Games where the sum of payoffs to all players is constant (usually zero). A gain for MAX is an exact, equal loss for MIN: UtilityMAX(s)=−UtilityMIN(s)Utility_{MAX}(s) = -Utility_{MIN}(s)UtilityMAX​(s)=−UtilityMIN​(s).

  • Deterministic, fully observable, zero-sum games: Chess, Checkers, Go, Tic-Tac-Toe.

The Minimax Algorithm

§ 2

The Minimax algorithm computes the optimal move for player MAX under the assumption that the adversary MIN plays perfectly (optimally) to minimize MAX's outcome.

Minimax(s)={Utility(s)if TerminalTest(s)max⁡a∈Actions(s)Minimax(Result(s,a))if Player(s)=MAXmin⁡a∈Actions(s)Minimax(Result(s,a))if Player(s)=MIN\mathbf{\text{Minimax}(s) = \begin{cases} \text{Utility}(s) & \text{if } TerminalTest(s) \\ \max_{a \in Actions(s)} \text{Minimax}(Result(s, a)) & \text{if } Player(s) = MAX \\ \min_{a \in Actions(s)} \text{Minimax}(Result(s, a)) & \text{if } Player(s) = MIN \end{cases}}Minimax(s)=⎩⎨⎧​Utility(s)maxa∈Actions(s)​Minimax(Result(s,a))mina∈Actions(s)​Minimax(Result(s,a))​if TerminalTest(s)if Player(s)=MAXif Player(s)=MIN​

Properties of the Minimax Algorithm

  • Completeness: Yes, if the game tree is finite.
  • Optimality: Yes, against an optimal adversary. (If the opponent plays suboptimally, Minimax still guarantees at least the minimax value or better).
  • Time Complexity: O(bm)O(b^m)O(bm), where bbb is the legal branching factor and mmm is the maximum depth of the game tree. Performs a full depth-first exploration.
  • Space Complexity: O(bm)O(bm)O(bm) — linear space for depth-first recursion.
THE INTRACTABILITY OF PURE MINIMAX

For Chess (b≈35,m≈80b \approx 35, m \approx 80b≈35,m≈80), Minimax would evaluate 3580≈1012335^{80} \approx 10^{123}3580≈10123 terminal nodes! In comparison, the observable universe contains only ∼1080\sim 10^{80}∼1080 atoms. Pure Minimax cannot be computed completely; practical game programs use Alpha-Beta Pruning combined with heuristic evaluation functions and depth cutoffs.

QUICK RECALL
  • MAX chooses action maximizing child values (max⁡\maxmax).
  • MIN chooses action minimizing child values (min⁡\minmin).
  • Time: O(bm)O(b^m)O(bm) (exponential); Space: O(bm)O(bm)O(bm) (linear).

Alpha-Beta Pruning

§ 3

Alpha-Beta pruning is a pruning technique that returns the exact same mathematical decision as Minimax, but systematically eliminates subtrees that cannot possibly influence the final decision.

THE TWO BOUNDING PARAMETERS
  • α\alphaα (Alpha): The value of the best (highest-value) choice found so far along the path for MAX. Initialized to −∞-\infty−∞.
  • β\betaβ (Beta): The value of the best (lowest-value) choice found so far along the path for MIN. Initialized to +∞+\infty+∞.
ALPHA-BETA PRUNING CUTOFF RULE

As search proceeds down the tree, the [α,β][\alpha, \beta][α,β] window shrinks. Whenever:

β≤α\mathbf{\beta \le \alpha}β≤α

the remaining children of the current node are pruned immediately (alpha cutoff at a MIN node, or beta cutoff at a MAX node).

Reason: MAX already has an option of value α\alphaα elsewhere, while MIN has an option of value ≤β\le \beta≤β here. Since β≤α\beta \le \alphaβ≤α, MAX will never allow the game to enter this branch!

Constraint Satisfaction Problems (CSP)

§ 4

Standard search treats states as atomic "black boxes" with no internal structure. In a Constraint Satisfaction Problem (CSP), states are factored into a set of variables, each taking a value from a domain, and the goal is to find an assignment that satisfies a set of explicit constraints.

FORMAL DEFINITION OF A CSP

A CSP is formally specified as a triplet:

{X,D,C}\mathbf{\{X, D, C\}}{X,D,C}
  • X={X1,X2,…,Xn}\mathbf{X = \{X_1, X_2, \dots, X_n\}}X={X1​,X2​,…,Xn​}: A finite set of variables.
  • D={D1,D2,…,Dn}\mathbf{D = \{D_1, D_2, \dots, D_n\}}D={D1​,D2​,…,Dn​}: A set of domains, where DiD_iDi​ is the set of allowable values for variable XiX_iXi​.
  • C={C1,C2,…,Cm}\mathbf{C = \{C_1, C_2, \dots, C_m\}}C={C1​,C2​,…,Cm​}: A set of constraints. Each constraint Ci=⟨scope,rel⟩C_i = \langle scope, rel \rangleCi​=⟨scope,rel⟩ consists of a tuple of variables that participate in the constraint and a relation defining allowable value combinations.

Constraint Taxonomy

  • Unary Constraint: Restricts the value of a single variable (e.g. SA≠GreenSA \ne \text{Green}SA=Green).
  • Binary Constraint: Relates two variables (e.g. SA≠WASA \ne WASA=WA). Binary CSPs can be visualized as a Constraint Graph where variables are nodes and constraints are edges.
  • Higher-Order / Global Constraints: Involve 3 or more variables. Classic example: Alldiff(X1,X2,…,Xk)\text{Alldiff}(X_1, X_2, \dots, X_k)Alldiff(X1​,X2​,…,Xk​), which mandates that all participating variables take distinct values (e.g. Sudoku).
QUICK RECALL
  • CSP = {X,D,C}\{X, D, C\}{X,D,C} (Variables, Domains, Constraints).
  • Constraint graph: Nodes = variables; Edges = binary constraints.
  • Consistent assignment: violates no constraints. Complete assignment: every variable is assigned.

Constraint Propagation & The AC-3 Arc Consistency Algorithm

§ 5

Rather than searching blindly, a CSP agent can interleave search with constraint propagation: using constraints to eliminate impossible values from variable domains before making choices.

DEFINITION: ARC CONSISTENCY

A directed arc (Xi,Xj)(X_i, X_j)(Xi​,Xj​) in the constraint graph is arc-consistent if and only if for every value x∈Dix \in D_ix∈Di​, there exists at least one value y∈Djy \in D_jy∈Dj​ such that the pair (x,y)(x, y)(x,y) satisfies the constraint between XiX_iXi​ and XjX_jXj​.

THE AC-3 ALGORITHM (STEP-BY-STEP)
  1. Initialize a queue QQQ with all directed binary arcs in the CSP: Q={(Xi,Xj)∣binary constraint exists between Xi,Xj}Q = \{(X_i, X_j) \mid \text{binary constraint exists between } X_i, X_j\}Q={(Xi​,Xj​)∣binary constraint exists between Xi​,Xj​}. (Each undirected constraint corresponds to two directed arcs (Xi,Xj)(X_i, X_j)(Xi​,Xj​) and (Xj,Xi)(X_j, X_i)(Xj​,Xi​)).
  2. While QQQ is not empty:
    • Remove arc (Xi,Xj)(X_i, X_j)(Xi​,Xj​) from QQQ.
    • Call Revise(CSP, Xi, Xj): For each x∈Dix \in D_ix∈Di​, if no value y∈Djy \in D_jy∈Dj​ satisfies the constraint with xxx, remove xxx from DiD_iDi​.

Backtracking Search & Intelligent Heuristics

§ 6

Backtracking search is the fundamental uninformed algorithm for solving CSPs. It performs depth-first search, assigning one variable at a time, and backtracks immediately when a variable has no legal values.

Three Intelligent Heuristics for CSP Search

Heuristic Name Selection Target Operational Rule & Intuition
1. Minimum Remaining Values (MRV)
(Most Constrained Variable / "Fail-First")		 Variable Selection Choose the unassigned variable with the fewest remaining legal values in its domain.
Intuition: Minimizes branching factor and detects inevitable failure as early as possible.
2. Degree Heuristic
(Tie-breaker for MRV)		 Variable Selection Choose the unassigned variable with the largest number of constraints on other unassigned variables.
Intuition: Imposes the greatest reduction on neighboring domains early in the search tree.
3. Least Constraining Value (LCV)
("Fail-Last")		 Value Selection Given a selected variable, choose the value that rules out the fewest choices for neighboring variables.
Intuition: Leaves maximum flexibility for subsequent variable assignments.
MNEMONIC: VARIABLE VS VALUE SELECTION

For choosing which variable to assign: be pessimistic → Fail-First (MRV, Degree Heuristic).

For choosing which value to assign: be optimistic → Fail-Last (Least Constraining Value).

QUICK RECALL
  • MRV (variable): pick variable with fewest legal values left.
  • Degree Heuristic (variable): tie-breaker; pick variable with most constraints on other unassigned variables.
  • LCV (value): pick value ruling out fewest choices for neighbors.

Forward Checking & Maintaining Arc Consistency (MAC)

§ 7

Instead of waiting for a contradiction, a search algorithm can detect dead-ends proactively by propagating constraints during the search process.

Forward Checking

Whenever a variable XXX is assigned a value xxx, Forward Checking looks ahead at each unassigned neighbor YYY connected to XXX by a constraint, and deletes from DYD_YDY​ any value that is inconsistent with xxx. If any domain becomes completely empty (DY=∅D_Y = \emptysetDY​=∅), the algorithm backtracks immediately!

LIMITATION OF FORWARD CHECKING

Forward checking only looks at constraints between the current variable and its neighbors. It does NOT detect inconsistencies between two unassigned neighbors! For example, if two unassigned neighbors both have domain {Green}\{Green\}{Green}, forward checking will not detect that they must conflict until one of them is assigned.

Maintaining Arc Consistency (MAC)

MAC is a more powerful algorithm: after a variable XiX_iXi​ is assigned, it runs a full AC-3 algorithm initialized with arcs (Xj,Xi)(X_j, X_i)(Xj​,Xi​) for all unassigned neighbors XjX_jXj​. MAC detects deep multi-variable contradictions that forward checking misses completely.

QUICK RECALL
  • Forward Checking: removes conflicting values from unassigned neighbors upon assignment.
  • Backtracks immediately if any neighbor's domain becomes empty.
  • MAC (Maintaining Arc Consistency): runs AC-3 after each assignment to detect multi-hop contradictions.

Ramaiah CIE-1 • October 29, 2025 • Question 2.c [4 Marks]

"Explain how α-β pruning enhances the efficiency of Minimax search. State the conditions under which branches are pruned."

📝 Practice Problem:
Show Complete Step-by-Step Model Answer
Ans

1. Efficiency Enhancement Principle:

Pure Minimax performs a full depth-first traversal of the entire game tree, evaluating O(bm)O(b^m)O(bm) states. In contrast, Alpha-Beta pruning maintains two bounding values (lpha and eta) along the path to determine when a branch cannot possibly alter the root's decision. It returns the exact same mathematical decision as Minimax, but prunes provably irrelevant subtrees.

2. Pruning Cutoff Condition:

A branch is pruned immediately whenever:

\mathbf{eta \le lpha}
  • Alpha Cutoff (at a MIN node): If a MIN node's current eta value drops less than or equal to the ancestor MAX node's guaranteed lpha score (eta \le lpha), the ancestor MAX will never choose this branch. Remaining children of this MIN node are pruned.
  • Beta Cutoff (at a MAX node): If a MAX node's lpha value rises above the ancestor MIN node's eta bound (lpha \ge eta), the ancestor MIN will never allow play to reach this state. Remaining children of this MAX node are pruned.

Heuristic Decision Target Selection Criterion Guiding Philosophy
Minimum Remaining Values (MRV) Variable Selection Choose the unassigned variable with the fewest legal values left in its domain. "Fail-First" Principle: Prunes failing search subtrees immediately at shallow depths.
