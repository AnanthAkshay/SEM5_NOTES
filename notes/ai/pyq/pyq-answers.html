What are the types of AI? Explain both classification schemes (by capability and by functionality).

Model Exam Answer

1. Classification by Capability

  1. Narrow / Weak AI (ANI): AI trained and specialized for a single dedicated task. It excels in its domain but cannot generalize outside it.
    Examples: Apple Siri, Google Translate, AlphaGo, Tesla Autopilot. (All existing AI today is Narrow AI).
  2. General / Strong AI (AGI): Hypothetical AI possessing human-level cognitive capabilities across any intellectual task, capable of reasoning, abstract thinking, and transfer learning across domains.
  3. Super AI (ASI): Theoretical future AI surpassing human intelligence across all disciplines, including scientific creativity, emotional intelligence, and social skills.

2. Classification by Functionality (Hintze's Classification)

  • Type 1: Reactive Machines: Purely reactive; no memory or past experience used for decisions (e.g. IBM Deep Blue).
  • Type 2: Limited Memory: Can look into the past for short intervals to make current decisions (e.g. self-driving cars monitoring recent vehicle velocities).
  • Type 3: Theory of Mind: (Under research) AI that understands that humans and other entities have thoughts, emotions, and beliefs affecting their behavior.
  • Type 4: Self-Aware AI: (Hypothetical) AI possessing conscious awareness of self and internal states.

📖 Theory Link: Unit 1 § 2

What is a rational agent? Explain the four factors that determine rationality and differentiate rationality from omniscience.

Model Exam Answer

1. Definition of Rationality

A rational agent is one that does the right thing. Specifically, for each possible percept sequence, a rational agent selects an action expected to maximize its performance measure, based on the evidence provided by the percept sequence and whatever built-in knowledge the agent possesses.

2. Four Factors Determining Rationality

  1. Performance Measure: Defines the criterion of success for evaluating the sequence of environment states.
  2. Prior Knowledge: The agent's initial background knowledge about its operational environment.
  3. Percept Sequence: The historical sequence of observations received up to the current moment ($P^*$).
  4. Action Set: The set of physical or logical actions that the agent is capable of executing.

3. Rationality $\neq$ Omniscience

  • An omniscient agent knows the actual outcome of its actions and can act accordingly; but omniscience is impossible in reality.
  • Rationality is about maximizing expected performance given the information available, whereas omniscience maximizes actual outcome. Rationality does not require clairvoyance!
Source: Russell & Norvig, Chapter 2.2, pp. 39–42

Discuss the different types of intelligent agent architectures (Simple Reflex, Model-Based, Goal-Based, Utility-Based, and Learning Agents) with schematic diagrams.

Model Exam Answer

Five Core Agent Architectures

  1. Simple Reflex Agent: Selects actions based solely on the current percept, ignoring history, using Condition-Action Rules (IF car-in-front-braking THEN brake). Fails in partially observable environments.
    Pseudocode: function SimpleReflex(percept): state = Interpret(percept); rule = RuleMatch(state, rules); return rule.Action.
  2. Model-Based Reflex Agent: Maintains an internal state tracking aspects of the environment that cannot be seen currently (updates internal model: 'How the world evolves' and 'How my actions affect the world'). Can handle partial observability.
  3. Goal-Based Agent: Combines internal state information with a goal description to select actions that achieve desired future states. Uses search and planning.
  4. Utility-Based Agent: Uses a utility function ($U: S \rightarrow \mathbb{R}$) mapping states to a real number expressing the degree of happiness or desirability. Enables trade-offs between conflicting goals under uncertainty.
  5. Learning Agent: Divided into four conceptual components:
    • Learning Element: Responsible for making improvements.
    • Performance Element: Responsible for selecting external actions (equivalent to entire agent previously).
    • Critic: Evaluates agent behavior against an external performance standard.
    • Problem Generator: Suggests exploratory actions leading to new experiences.
Source: Russell & Norvig, Chapter 2.4, pp. 49–58

Environment consists of two locations: Square $A$ and Square $B$. Each square can be either Clean or Dirty. The agent can perceive its location and cleanliness: $[A, \text{Dirty}]$, $[A, \text{Clean}]$, $[B, \text{Dirty}]$, $[B, \text{Clean}]$.

2. Reflex Agent Action Rules

function VacuumReflexAgent([location, status]):
    if status == 'Dirty':
        return 'Suck'
    else if location == 'A':

    else if location == 'B':

An online chess-playing system competes against human grandmasters. Analyze its task environment properties across the 7 standard environment dimensions.

Model Exam Answer

Task Environment Characterization for Chess AI

  1. Fully Observable vs Partially Observable: Fully Observable. The complete board state and all piece positions are known to the agent at every turn.
  2. Single-Agent vs Multi-Agent: Multi-Agent (Competitive). The agent plays against an opponent whose objective directly opposes the agent's objective.
  3. Deterministic vs Stochastic: Deterministic. There is no randomness or dice; moving a piece to square $X$ results with certainty in that piece occupying $X$.
  4. Episodic vs Sequential: Sequential. Current moves fundamentally alter the future board position; actions have long-term consequences.
  5. Static vs Dynamic: Semi-Dynamic. The physical board does not change while the agent thinks, but there is a time clock ticking down.
  6. Discrete vs Continuous: Discrete. There are a finite number of distinct squares, distinct pieces, and legal turns.
  7. Known vs Unknown: Known. The rules of chess are completely known and programmed into the game engine.

Explain how Bidirectional Search is efficient compared to BFS and DFS methods. Show the BFS and DFS traversal for the following graph to reach goal state G: Root A with children B, C; B has children D, E; C has child F; F has child G.

Model Exam Answer

1. Efficiency of Bidirectional Search

  • Standard BFS searches forward from initial state to depth $d$ with branching factor $b$, requiring time and space $O(b^d)$.
  • Bidirectional Search runs two simultaneous searches: one forward from the initial state, and one backward from the goal, stopping when the two search frontiers meet in the middle!
  • Complexity becomes $O(b^{d/2} + b^{d/2}) = O(2 b^{d/2})$, which is an exponential reduction! E.g. for $b = 10, d = 6$, $b^d = 1,000,000$ nodes vs $2 b^{d/2} = 2 \times 10^3 = 2,000$ nodes (a 500-fold reduction).

2. Traversal on Given Graph

Tree structure: $A \rightarrow \{B, C\}$, $B \rightarrow \{D, E\}$, $C \rightarrow \{F\}$, $F \rightarrow \{G\}$. Goal is $G$.

  • BFS (Breadth-First Traversal - Level by Level, FIFO Queue):
    1. Visit Level 0: A
    2. Visit Level 1: B, C
    3. Visit Level 2: D, E, F
    4. Visit Level 3: G (Goal reached!)
    • Order of visited nodes: A → B → C → D → E → F → G.
  • DFS (Depth-First Traversal - Deepest Node First, LIFO Stack):
    Assuming left-to-right branch exploration:
    1. Explore left subtree: A → B → D (dead end, backtrack to B)
    2. Explore next branch: E (dead end, backtrack to A)
    3. Explore right subtree: C → F → G (Goal reached!)
    • Order of visited nodes: A → B → D → E → C → F → G.
Source: Russell & Norvig, Chapter 3.4.6, pp. 94–96

Solve the 8-puzzle problem using A* search algorithm. Given Start State [1, _, 3 / 4, 2, 6 / 7, 5, 8] and Goal State [1, 2, 3 / 4, 5, 6 / 7, 8, _]. Find the most cost-effective path (consider g(n) = depth and h(n) = number of misplaced tiles).

Model Exam Answer

1. Evaluation Function

$$f(n) = g(n) + h(n)$$
  • $g(n)$: Path cost from root (depth level).
  • $h(n)$: Number of misplaced tiles compared to Goal State $[1, 2, 3 / 4, 5, 6 / 7, 8, \text{blank}]$. (Blank tile is not counted).

2. Step-by-Step Search Tree Trace

Step 0: Start State ($n_0$)

[ 1   _   3 ]
[ 4   2   6 ]
[ 7   5   8 ]
  • Compare with Goal $[1, 2, 3 / 4, 5, 6 / 7, 8, \_]$: Tiles 2, 5, 8 are in wrong positions $\implies h(n_0) = 3$.
  • $g(n_0) = 0 \implies f(n_0) = 0 + 3 = \mathbf{3}$.

Step 1: Expand Start Node (Valid moves for blank at top-middle: Left, Right, Down)

  • Move Left (Tile 1 moves Right): $[\_, 1, 3 / 4, 2, 6 / 7, 5, 8]$. Misplaced: 1, 2, 5, 8 ($h = 4$). $g = 1 \implies f = 1 + 4 = 5$.
  • Move Right (Tile 3 moves Left): $[1, 3, \_ / 4, 2, 6 / 7, 5, 8]$. Misplaced: 3, 2, 5, 8 ($h = 4$). $g = 1 \implies f = 1 + 4 = 5$.
  • Move Down (Tile 2 moves Up):
    [ 1   2   3 ]
[ 4   _   6 ]
[ 7   5   8 ]
    Misplaced tiles: 5, 8 are wrong ($h = 2$). $g = 1 \implies f(n_1) = 1 + 2 = \mathbf{3}$ ← MINIMUM $f(n)$!

Step 2: Expand Node $n_1$ (Blank at center: Up, Left, Right, Down)

  • Moving Up returns to parent (pruned).
  • Move Left: $[1, 2, 3 / \_, 4, 6 / 7, 5, 8]$. Misplaced: 4, 5, 8 ($h = 3$). $f = 2 + 3 = 5$.
  • Move Right: $[1, 2, 3 / 4, 6, \_ / 7, 5, 8]$. Misplaced: 6, 5, 8 ($h = 3$). $f = 2 + 3 = 5$.
  • Move Down (Tile 5 moves Up):
    [ 1   2   3 ]
[ 4   5   6 ]
[ 7   _   8 ]
    Misplaced tiles: 8 is wrong ($h = 1$). $g = 2 \implies f(n_2) = 2 + 1 = \mathbf{3}$ ← MINIMUM $f(n)$!

Step 3: Expand Node $n_2$ (Blank at bottom-middle: Move Right / Tile 8 moves Left)

[ 1   2   3 ]
[ 4   5   6 ]
[ 7   8   _ ]  <-- GOAL STATE REACHED!
  • All tiles in correct place: $h = 0$. $g = 3 \implies f = 3 + 0 = \mathbf{3}$.

Optimal Solution Path: $\text{Start} \xrightarrow{\text{Down}} n_1 \xrightarrow{\text{Down}} n_2 \xrightarrow{\text{Right}} \text{Goal State}$. Total Path Cost $= 3$ steps.

Explain Alpha-Beta Pruning. Define the terms alpha and beta, state their roles, and explain how alpha-beta pruning improves efficiency over standard minimax.

Model Exam Answer

1. Definition of Alpha and Beta

  • $\alpha$ (Alpha): The value of the best (highest-value) choice found so far at any choice point along the path for MAX. Initialized to $-\infty$.
  • $\beta$ (Beta): The value of the best (lowest-value) choice found so far at any choice point along the path for MIN. Initialized to $+\infty$.

2. Pruning Condition (Alpha-Beta Cutoff)

At any node, if $\alpha \ge \beta$, the remaining children of that node do not need to be evaluated and are pruned (cut off). Because the parent already has a guaranteed outcome that is better than whatever this sub-branch could yield.

3. Efficiency Improvement over Standard Minimax

  • Standard Minimax examines every leaf node in a tree with branching factor $b$ and depth $m$: Time complexity $O(b^m)$.
  • With perfect move ordering in Alpha-Beta pruning, the effective branching factor is reduced to $\sqrt{b}$. The time complexity drops to:$$O(b^{m/2})$$
  • This means Alpha-Beta pruning can search twice as deep in the same amount of CPU time as standard Minimax!
Source: Russell & Norvig, Chapter 5.3, pp. 167–172

📖 Theory Link: Unit 2 § 1

Why is uninformed search known as blind search? Explain Uniform Cost Search (UCS) with a suitable example.

Model Exam Answer

1. Why Uninformed Search is 'Blind Search'

Uninformed search algorithms (BFS, DFS, Uniform Cost Search) have no domain-specific knowledge about how close a given state is to the goal. They can only generate successors and distinguish a goal state from a non-goal state; they have no clue whether one non-goal node is more promising than another.

2. Uniform Cost Search (UCS / Dijkstra's Algorithm)

  • Instead of expanding the shallowest node (BFS), UCS expands the unvisited node with the lowest path cost $g(n)$ from the root.
  • Implemented using a priority queue ordered by cumulative path cost $g(n)$.
  • Completeness & Optimality: Guaranteed to find the optimal path if every step cost exceeds a positive constant $\epsilon > 0$.

3. Example: Route from S to G

Edges: $S \rightarrow A$ (cost 1), $S \rightarrow B$ (cost 5), $A \rightarrow G$ (cost 10), $B \rightarrow G$ (cost 2).

  1. Init: Frontier $= \{[S, g=0]\}$.
  2. Expand S: Add $A$ ($g=1$), $B$ ($g=5$). Frontier $= \{[A, 1], [B, 5]\}$.
  3. Expand A (min cost $g=1$): Add $G$ ($g=1+10=11$). Frontier $= \{[B, 5], [G, 11]\}$.
  4. Expand B (min cost $g=5$): Add $G$ ($g=5+2=7$). Shorter path to G found! Frontier $= \{[G, 7]\}$.
  5. Expand G ($g=7$): Goal reached! Optimal path is $S \rightarrow B \rightarrow G$ with cost 7.
Source: Russell & Norvig, Chapter 3.4.2, pp. 83–86

What is an admissible heuristic? What is a consistent (monotonic) heuristic? Prove that A* tree search is optimal if h(n) is admissible.

Model Exam Answer

1. Admissible Heuristic

A heuristic function $h(n)$ is admissible if it never overestimates the true cost to reach the nearest goal state from node $n$:

$$0 \le h(n) \le h^*(n) \quad \forall n$$

where $h^*(n)$ is the true optimal path cost from $n$ to goal. (E.g., Straight-line Euclidean distance is admissible for road navigation).

2. Consistent (Monotonic) Heuristic

A heuristic $h(n)$ is consistent if for every node $n$ and every successor $n'$ generated by action $a$ with step cost $c(n, a, n')$:

$$h(n) \le c(n, a, n') + h(n')$$

(Satisfies the triangle inequality. Every consistent heuristic is also admissible).

3. Proof Sketch: A* is Optimal with Admissible Heuristic

  • Suppose suboptimal goal $G_2$ is in the queue with $f(G_2) = g(G_2) > C^*$ (where $C^*$ is optimal cost).
  • Let $n$ be an unexpanded node on the optimal path to true optimal goal $G_1$.
  • Since $h$ is admissible: $f(n) = g(n) + h(n) \le g(n) + h^*(n) = C^*$.
  • Therefore: $f(n) \le C^* < f(G_2)$.
  • Since A* always expands the node with minimum $f$ in the priority queue, node $n$ will always be selected before $G_2$. Hence $G_2$ can never be selected for expansion, guaranteeing A* returns the optimal goal!
Source: Russell & Norvig, Chapter 3.5.2, pp. 102–106

Explain the Hill-Climbing search algorithm and discuss the three major problems that cause it to fail (Local Maxima, Ridges, and Plateaux).

Model Exam Answer

1. Hill-Climbing Search Principle

Hill-climbing (Greedy Local Search) is an iterative optimization algorithm that continuously moves in the direction of increasing elevation (value) to find the peak of a state landscape. It maintains only the current state and looks at its immediate neighbors.

2. Three Major Failure Modes

  1. Local Maxima: A peak that is higher than each of its neighboring states, but lower than the global maximum. Since all neighboring moves look worse, the algorithm terminates prematurely.
  2. Ridges: A sequence of local maxima connected together. The slope orientation causes navigation steps that zigzag without progressing toward the summit because single-direction orthogonal steps drop off on either side.
  3. Plateaux (Flat Local Maxima / Shoulders): A flat area of the state space where all neighboring states have identical heuristic evaluation values. The search wanders aimlessly without guidance.

3. Remedial Variants

  • Random-restart hill climbing: Conducts multiple hill-climbing runs starting from randomly chosen initial states.
  • Simulated Annealing: Escapes local maxima by allowing occasional downhill moves with a probability that decreases over time (temperature cooling schedule).
Source: Russell & Norvig, Chapter 4.1.1, pp. 122–126

Describe the Genetic Algorithm (GA) approach to local search. Explain its four core operators.

Model Exam Answer

1. Genetic Algorithm (GA) Workflow

Genetic algorithms are stochastic local search algorithms inspired by biological natural selection. A population of candidate solutions (encoded as strings over a finite alphabet, e.g. binary chromosomes) evolves over generations toward higher fitness.

2. Four Core Operators

  1. Initial Population: A collection of randomly generated individual states.
  2. Fitness Function: Evaluates each individual state and returns a numerical fitness score (e.g. number of non-attacking queen pairs in 8-queens). Higher fitness means higher probability of selection.
  3. Selection & Crossover: Pairs of individuals are selected for reproduction based on fitness (roulette wheel or tournament selection). A crossover point is chosen randomly, and substrings are swapped to produce offspring.
  4. Mutation: Each gene (character) in the offspring is flipped or modified with a small independent probability (mutation rate $\approx 0.01$), introducing diversity and preventing premature convergence.
Source: Russell & Norvig, Chapter 4.1.4, pp. 130–133

How can Artificial Intelligence solve the Tic-Tac-Toe problem? Explain with the help of a game tree representation.

Model Exam Answer

1. Game Tree for Tic-Tac-Toe

Tic-Tac-Toe is a 2-player, zero-sum, perfect-information, discrete, deterministic game played on a $3 \times 3$ grid.

  • Root: Initial empty $3 \times 3$ board ($9$ possible moves for Player MAX / 'X').
  • Level 1: 9 possible board states. Player MIN ('O') can choose from remaining 8 empty squares.
  • Terminal States: A board where a player has 3 in a row (Utility: $+1$ if MAX wins, $-1$ if MIN wins, $0$ if Draw), or all 9 squares are full.

2. Minimax Solution & Optimal Play

  • Total state space is small: at most $9! = 362,880$ leaf nodes (reduced to $26,830$ legal states via symmetry).
  • Minimax searches the complete game tree to the terminal leaves and backs up optimal values.
  • With optimal Minimax play, every game of Tic-Tac-Toe guarantees a Draw (Utility = 0); MAX can never be beaten!
Source: Russell & Norvig, Chapter 5.1, pp. 161–164
