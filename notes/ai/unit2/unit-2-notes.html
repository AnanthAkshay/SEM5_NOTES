§ 1

Uninformed (Blind) Search Strategies

Uninformed search (also termed blind search) refers to strategies that have no additional information about states beyond that provided in the problem definition. They can generate successors and distinguish a goal state from a non-goal state, but cannot estimate how close a non-goal state is to the destination.

1. Breadth-First Search (BFS)

BFS expands the shallowest unexpanded node first using a First-In First-Out (FIFO) queue frontier. All nodes at depth $d$ are expanded before any nodes at depth $d + 1$.

  • Completeness: Yes (if branching factor $b$ is finite).
  • Time Complexity: $O(b^d)$, where $b$ is the branching factor and $d$ is the depth of the shallowest goal.
  • Space Complexity: $O(b^d)$ — every generated node must remain in memory. Memory is the fatal bottleneck of BFS!
  • Optimality: Yes, if all step costs are equal; otherwise not necessarily optimal.

2. Uniform-Cost Search (UCS / Dijkstra on Trees)

UCS expands the node $n$ with the lowest path cost $g(n)$ from the start node using a Priority Queue ordered by $g(n)$.

  • Goal Test Timing: The goal test is applied when a node is selected for expansion (popped from the priority queue), NOT when it is first generated!
  • Completeness: Yes, provided every step cost is strictly positive ($c(s, a, s') \ge \epsilon > 0$).
  • Time & Space Complexity: $O(b^{1 + \lfloor C^* / \epsilon \rfloor})$, where $C^*$ is the cost of the optimal solution and $\epsilon$ is the minimal step cost.
  • Optimality: Yes! UCS is guaranteed to find the cheapest path for arbitrary non-negative step costs.

3. Depth-First Search (DFS)

DFS expands the deepest unexpanded node first using a Last-In First-Out (LIFO) stack frontier.

  • Completeness: No in infinite-depth spaces or spaces with loops (unless cycle-checking graph search is used); Yes in finite state spaces.
  • Time Complexity: $O(b^m)$, where $m$ is the maximum depth of the state space ($m \gg d$).
  • Space Complexity: $O(bm)$ — only needs to store a single path from the root to a leaf plus unexpanded sibling nodes. Linear memory advantage!
  • Optimality: No — it can return a deeply nested suboptimal goal before exploring a shallow optimal one.

4. Iterative Deepening Depth-First Search (IDDFS)

IDDFS solves the dilemma between BFS (optimal, but exponential memory) and DFS (linear memory, but non-optimal and incomplete). It repeatedly runs Depth-Limited Search (DLS) with increasing depth limits ($l = 0, 1, 2, 3, \dots, d$).

WHY IDDFS IS THE PREFERRED UNINFORMED SEARCH METHOD

Although it appears wasteful to re-generate nodes from earlier depths, the bottom layer dominates the expansion cost in exponential trees. The number of generated nodes in IDDFS is:

$$N(\text{IDDFS}) = (d)b^1 + (d-1)b^2 + \dots + (1)b^d = O(b^d)$$

For $b = 10, d = 5$, BFS generates 111,111 nodes while IDDFS generates 123,450 nodes (only ~11% overhead!). IDDFS combines the completeness and optimality of BFS with the modest $O(bd)$ linear memory storage of DFS.

QUICK RECALL
  • BFS: FIFO queue, $O(b^d)$ time & space, optimal for unit costs. Space is the killer.
  • UCS: Priority queue ordered by $g(n)$, goal test on POP, optimal for non-negative costs.
  • DFS: LIFO stack, $O(bm)$ linear space, not optimal, incomplete on infinite trees.
  • IDDFS: Runs DLS with limit $0, 1, 2, \dots, d$. Combines BFS optimality with DFS $O(bd)$ linear space!
Source: Russell & Norvig 4e, Ch. 3.3, pp. 71–81; slides 19–32

§ 3

Informed Search & Heuristic Functions

Informed search strategies utilize problem-specific knowledge beyond the problem definition via a heuristic function $h(n)$, enabling the search to prune barren paths and focus exploration directly toward the goal.

HEURISTIC FUNCTION DEFINITION

A heuristic function $h(n)$ estimates the cost of the cheapest path from the state at node $n$ to a goal state:

$$h(n) = \text{Estimated cost of shortest path from } n \text{ to Goal}$$

Property: If $n$ is a goal node itself, then $h(n) = 0$.

Greedy Best-First Search vs $A^*$ Search

Search Algorithm Evaluation Function $f(n)$ Behavioral Logic Completeness & Optimality
Greedy Best-First Search $$f(n) = h(n)$$ Expands the node that appears closest to the goal. Short-sighted: completely ignores past path cost $g(n)$. Incomplete (can get trapped in loops); Non-optimal. Worst-case time/space $O(b^m)$.
$A^*$ Search $$f(n) = g(n) + h(n)$$ Combines past cost $g(n)$ (cost to reach $n$) with estimated future cost $h(n)$. $f(n)$ is estimated cost of cheapest solution passing through $n$. Complete and Optimal under appropriate heuristic conditions (Admissibility / Consistency).
QUICK RECALL
  • $h(n)$: estimated cost from $n$ to goal ($h(\text{goal}) = 0$).
  • Greedy Best-First: $f(n) = h(n)$ (fast but non-optimal and incomplete).
  • $A^*$ Search: $f(n) = g(n) + h(n)$ (optimal and complete).
Source: Russell & Norvig 4e, Ch. 3.5, pp. 96–107; AI-Informed_Search.pdf slides 1–35
§ 4

$A^*$ Search: Conditions for Optimality (Admissibility & Consistency)

$A^*$ is the most widely celebrated search algorithm in computer science. However, its guarantee of optimality relies strictly on mathematical conditions governing the heuristic function.

1. ADMISSIBILITY (REQUIRED FOR TREE SEARCH)

An admissible heuristic is one that never overestimates the true cost to reach the goal. That is, $h(n)$ is optimistic:

$$\mathbf{h(n) \le h^*(n) \quad \forall n}$$

where $h^*(n)$ is the true, optimal cost to reach the nearest goal from $n$.

Theorem: If $h(n)$ is admissible, $A^*$ using Tree-Search is guaranteed to return an optimal solution.

2. CONSISTENCY / MONOTONICITY (REQUIRED FOR GRAPH SEARCH)

A heuristic $h(n)$ is consistent (or monotonic) if, for every node $n$ and every successor $n'$ generated by action $a$:

$$\mathbf{h(n) \le c(n, a, n') + h(n')}$$

Geometric Intuition: This is a form of the Triangle Inequality. The estimated cost from $n$ to the goal cannot exceed the step cost to step $n'$ plus the estimated cost from $n'$ to the goal.

Theorem: If $h(n)$ is consistent, $A^*$ using Graph-Search is guaranteed to be optimal. Furthermore, the first time $A^*$ expands any node $n$, the path to $n$ is guaranteed to be optimal; hence nodes placed on the Closed list never need to be reopened!

RELATIONSHIP BETWEEN ADMISSIBILITY & CONSISTENCY

Every consistent heuristic is admissible ($Consistency \implies Admissibility$). While an admissible heuristic can occasionally be inconsistent in rare contrived graphs, virtually all natural heuristics derived from relaxed problems are automatically consistent.

Heuristics for the 8-Puzzle & Heuristic Dominance

A standard method for generating admissible heuristics is to compute the exact cost of a solution to a relaxed problem (a problem with fewer restrictions on the actions).

Two Classical 8-Puzzle Heuristics

  1. $h_1(n)$ — Number of Misplaced Tiles:

    Count the number of tiles that are not in their goal position. (If a tile can move anywhere instantly, each misplaced tile needs at least 1 move). Clearly admissible: $h_1(n) \le h^*(n)$.

  2. $h_2(n)$ — Manhattan Distance (City Block Distance):

    The sum of the horizontal and vertical distances of each tile from its target goal position:

    $$h_2(n) = \sum_{i=1}^{8} \left( |x_i - x_{i,\text{goal}}| + |y_i - y_{i,\text{goal}}| \right)$$

    Admissible because each move can reduce the Manhattan distance of at most one tile by at most 1.

HEURISTIC DOMINANCE

If $h_2(n) \ge h_1(n)$ for all nodes $n$, and both are admissible, we say that $h_2$ dominates $h_1$.

Consequence: $A^*$ using $h_2$ will never expand more nodes than $A^*$ using $h_1$ (except possibly for some nodes on the boundary where $f(n) = C^*$). A dominating heuristic translates directly to greater pruning power and faster search!

For the 8-puzzle: since Manhattan distance counts the minimum moves for each tile to reach home and each misplaced tile is at least 1 step away, $h_2(n) \ge h_1(n)$ always holds. Manhattan distance strictly dominates misplaced tiles.

QUICK RECALL
  • Relaxed problem: removing constraints yields admissible heuristics.
  • 8-puzzle: $h_1$ = misplaced tiles; $h_2$ = Manhattan distance ($\sum |\Delta x| + |\Delta y|$).
  • $h_2$ dominates $h_1 \iff h_2(n) \ge h_1(n) \implies h_2$ expands fewer nodes.
Source: Russell & Norvig 4e, Ch. 4.1, pp. 120–135; AI-Local_Search.pdf slides 1–40
§ 6

Local Search Algorithms & Optimization

In many problems (such as the 8-queens, VLSI circuit layout, or factory scheduling), the path to the goal is completely irrelevant; only the final goal state itself matters. Local search algorithms operate using a single current state (rather than multiple paths) and generally move only to neighbors of that state, requiring $O(1)$ constant memory.

State Space Landscape & Local Search Hazards

Hill-Climbing Search (Greedy Local Search)

Hill-climbing simply loops continuously in the direction of increasing value (uphill). It terminates when it reaches a peak where no neighbor has a higher value.

THREE CLASSIC FAILURE MODES OF HILL CLIMBING
  1. Local Maxima: A peak that is higher than each of its neighbors, but lower than the global maximum. The algorithm terminates prematurely.
  2. Ridges: A sequence of local maxima where the slope gently rises along a diagonal ridge, but the allowable orthogonal moves all lead downhill.
  3. Plateaux: A flat area of the state space landscape where all neighbors have the identical value. The algorithm wanders aimlessly in a random walk.

Remedy — Random-Restart Hill Climbing: Conducts a series of hill-climbing searches from randomly generated initial states until a goal is found. Theorem: If each hill-climb has probability $p$ of success, expected number of restarts is $1/p$. Trivially complete with probability 1!

QUICK RECALL
  • Local search operates on complete-state representations with $O(1)$ memory.
  • Hill climbing moves greedily uphill; gets stuck on local maxima, ridges, and plateaux.
  • Random-Restart Hill Climbing guarantees finding global optimum given sufficient restarts.
Source: Russell & Norvig 4e, Ch. 5.1–5.3, pp. 161–175; AI-Adversarial_Search.pdf slides 1–45
§ 7

Simulated Annealing & Genetic Algorithms

To escape local maxima, an algorithm must occasionally make downhill moves. Two primary nature-inspired stochastic optimization methods achieve this: Simulated Annealing (thermodynamics) and Genetic Algorithms (biological evolution).

1. Simulated Annealing

Inspired by the metallurgical process of annealing (heating metal to high temperatures and cooling it slowly to form a crystal with minimal energy defects).

SIMULATED ANNEALING ALGORITHM

At each step, choose a random neighbor state $next$. Let $\Delta E = Value(next) - Value(current)$:

  • If $\Delta E > 0$ (the move improves objective value), always accept the move.
  • If $\Delta E \le 0$ (the move is worse / downhill), accept the move with probability: $$\mathbf{P = e^{\frac{\Delta E}{T}}}$$ where $T > 0$ is a control parameter called the Temperature, governed by a cooling schedule.

Downhill Acceptance Probabilities in Simulated Annealing

In simulated annealing, an agent encounters a bad downhill move with energy penalty $\Delta E = -5$. Compute the acceptance probability $P = e^{\Delta E / T}$ at temperatures $T = 1000, 100, 10, 1$.

Temperature $T$ Exponent $\Delta E / T$ Probability $P = e^{\Delta E / T}$ Physical / Algorithmic Behavior
$T = 1000\text{ K}$ (Hot) $-5 / 1000 = -0.005$ $e^{-0.005} \approx \mathbf{0.9950\ (99.50\%)}$ Almost all downhill moves accepted; behaves like random walk to escape traps.
$T = 100\text{ K}$ (Warm) $-5 / 100 = -0.05$ $e^{-0.05} \approx \mathbf{0.9512\ (95.12\%)}$ High exploration, readily navigates ridges.
$T = 10\text{ K}$ (Cooling) $-5 / 10 = -0.5$ $e^{-0.5} \approx \mathbf{0.6065\ (60.65\%)}$ Moderate exploration; bad moves increasingly penalized.
$T = 1\text{ K}$ (Cold) $-5 / 1 = -5.0$ $e^{-5.0} \approx \mathbf{0.0067\ (0.67\%)}$ Freezes into pure greedy hill climbing; downhill moves rejected.

Conclusion: If the cooling schedule lowers $T$ slowly enough, the algorithm is proven to converge to the global optimum with probability 1!

2. Genetic Algorithms (GAs)

A variant of stochastic beam search where successor states are generated by combining two parent states (crossover) rather than modifying a single state.

1
Representation: A state is encoded as a string over a finite alphabet (a chromosome / string of digits, e.g. 8-queens encoded as an 8-digit string indicating the row position of queen in each column).
2
Fitness Function: Evaluates the quality of each state (e.g. number of non-attacking queen pairs, maximum = 28).
3
Selection: Pairs of individuals are chosen for reproduction with probability proportional to their fitness (Roulette-wheel selection).
4
Crossover: A random crossover point is chosen. Offspring inherit the first segment from parent 1 and the remainder from parent 2.
5
Mutation: Each bit/digit is randomly mutated with a small independent probability (e.g. 1%) to maintain genetic diversity.
QUICK RECALL
  • Simulated Annealing accepts downhill moves with probability $P = e^{\Delta E / T}$. High $T$ = random walk; Low $T$ = greedy hill climb.
  • Genetic Algorithms: Population, Fitness proportional selection, Crossover, Mutation.
  • 8-queens can be encoded as an 8-character string with fitness = non-attacking pairs.

Blind Search Complexities

  • BFS: FIFO, $O(b^d)$ time, $O(b^d)$ space, optimal for unit cost.
  • UCS: Priority queue $g(n)$, goal test on pop, optimal for general costs.
  • DFS: LIFO, $O(b^m)$ time, $O(bm)$ linear space, non-optimal.
  • IDDFS: $O(b^d)$ time, $O(bd)$ linear space, optimal and complete!

A* Search Checklist

  • $f(n) = g(n) + h(n)$.
  • Admissibility: $h(n) \le h^*(n)$ (optimistic). Optimal for tree search.
  • Consistency: $h(n) \le c(n, a, n') + h(n')$ (triangle inequality). Optimal for graph search.
  • $Consistency \implies Admissibility$.

8-Puzzle Heuristics

  • $h_1$: misplaced tiles ($h_1 \le h^*$).
  • $h_2$: Manhattan distance ($\sum |\Delta x| + |\Delta y|$).
  • $h_2$ dominates $h_1$ ($h_2(n) \ge h_1(n)$) $\implies$ expands fewer nodes.

Local Search & Annealing

  • Hill climbing: gets stuck on local maxima, ridges, plateaux.
  • Simulated Annealing: accepts downhill moves with $P = e^{\Delta E / T}$.
  • High $T \implies P \approx 1$; Low $T \implies P \approx 0$.
  • Genetic Algorithms: Selection, Crossover, Mutation.

Important Examination Questions

2-Mark Questions (Short Answer)

2M Define an admissible heuristic function.

Answer: A heuristic function $h(n)$ is admissible if it never overestimates the true cost to reach the goal from node $n$, i.e., $h(n) \le h^*(n)$ for all nodes $n$, where $h^*(n)$ is the true optimal cost to the goal.

2M Why is IDDFS preferred over BFS and DFS?

Answer: IDDFS combines the best benefits of both algorithms: it achieves the completeness and optimality of BFS while requiring only the modest linear memory storage $O(bd)$ of DFS.

2M What is the acceptance probability formula in simulated annealing?

Answer: $P = e^{\Delta E / T}$, where $\Delta E < 0$ is the change in objective energy/value for a downhill move, and $T > 0$ is the temperature parameter.

5-Mark Questions (Medium Length)

5M Prove that consistency of a heuristic implies admissibility.

Answer:

  1. By consistency, $h(n) \le c(n, a, n') + h(n')$.
  2. Applying this along the sequence of nodes on the optimal path from $n$ to goal $G$: $$h(n) \le c(n, a_1, n_1) + h(n_1) \le c(n, a_1, n_1) + c(n_1, a_2, n_2) + \dots + h(G)$$
  3. Since $G$ is a goal node, $h(G) = 0$.
  4. The sum of the step costs along the optimal path is exactly $h^*(n)$.
  5. Therefore, $h(n) \le h^*(n)$, proving $h(n)$ is admissible.
5M Explain the failure modes of hill-climbing search.

Answer:

  • Local Maxima: Peaks that are higher than all neighbors but lower than the global maximum; search stops prematurely.
  • Ridges: Sequences of local maxima where the slope gently inclines along a ridge, but individual orthogonal moves lead downhill, causing oscillation.
  • Plateaux: Flat areas where all neighboring states have the same value; search degenerates into a random walk.

"Describe Bidirectional Search. Trace BFS and DFS traversal for the given graph from source S to goal G."

Show Complete Step-by-Step Model Answer

1. Principle of Bidirectional Search:

Bidirectional search replaces a single forward search from initial state $S$ to goal $G$ with two simultaneous searches: one forward from $S$, and one backward from $G$. Search terminates successfully when the two search frontiers intersect in the middle.

  • If the branching factor is $b$ and optimal goal distance is $d$, standard BFS expands $O(b^d)$ nodes.
  • Bidirectional BFS runs two trees of depth $d/2$, expanding $O(b^{d/2} + b^{d/2}) = \mathbf{O(2b^{d/2})}$ nodes.
  • Dramatic Speedup: For $b=10$ and $d=6$, standard BFS expands $10^6 = 1,000,000$ nodes, whereas bidirectional BFS expands only $2 imes 10^3 = \mathbf{2,000 ext{ nodes}}$ — a $500 imes$ reduction!

"Compare Uninformed Search with Uniform Cost Search (UCS). Explain their time and space complexities."

Show Complete Step-by-Step Model Answer

1. Distinction:

  • Standard Uninformed Search (BFS): Expands nodes in FIFO order based purely on tree depth (number of hops from root). Assumes all action step costs are identical ($c=1$).
  • Uniform Cost Search (UCS / Dijkstra's Search): Expands nodes in order of accumulated path cost $g(n)$ using a priority queue. Works on arbitrary, non-uniform positive edge step costs $c(s, a, s') \ge \epsilon > 0$.

2. Complexity Derivation:

  • Let $C^*$ be the optimal path cost to the goal, and let $\epsilon$ be the minimum step cost between any two connected nodes.
  • In the worst case, the search may explore nodes along paths up to depth $\lfloor C^* / \epsilon floor$.
  • Time Complexity: $$\mathbf{O\left(b^{1 + \lfloor C^* / \epsilon floor} ight)}$$ If all step costs are equal ($\epsilon = c$), then $C^* / \epsilon = d$, and time complexity simplifies to $O(b^d)$, matching standard BFS.
  • Space Complexity: $$\mathbf{O\left(b^{1 + \lfloor C^* / \epsilon floor} ight)}$$ UCS must store all explored and frontier nodes in the priority queue to maintain global minimum-cost ordering.

3. Optimality Condition:

UCS is guaranteed optimal if and only if all step costs are strictly positive ($c \ge \epsilon > 0$). If zero-cost or negative-cost cycles exist, UCS can enter infinite loops without advancing towards the goal.

"Prove the optimality of A* search for: (a) Tree search under an admissible heuristic, (b) Graph search under a consistent (monotonic) heuristic."

Show Complete Step-by-Step Model Answer

(a) Optimality Proof for Tree Search ($A^*$ with Admissible Heuristic):

  1. Suppose $G_2$ is a suboptimal goal node on the OPEN list, so $g(G_2) > C^*$, where $C^*$ is the optimal solution cost. Since $G_2$ is a goal node, $h(G_2) = 0$, giving $f(G_2) = g(G_2) > C^*$.
  2. Let $n$ be an unexpanded node on the OPEN list that lies on an optimal path to the optimal goal $G$.
  3. Because $h(n)$ is admissible ($h(n) \le h^*(n)$): $$f(n) = g(n) + h(n) \le g(n) + h^*(n) = C^*$$
  4. Combining both inequalities: $$f(n) \le C^* < f(G_2)$$
  5. Since $f(n) < f(G_2)$, the priority queue will pop node $n$ before $G_2$. By induction, all nodes on the optimal path are expanded before $G_2$ can ever be popped. Therefore, $A^*$ tree search never selects a suboptimal goal. $lacksquare$

(b) Optimality Proof for Graph Search ($A^*$ with Consistent Heuristic):

  1. A heuristic is consistent (monotonic) if for every node $n$ and every successor $n'$ generated by action $a$: $$h(n) \le c(n, a, n') + h(n')$$
  2. Adding $g(n)$ to both sides: $$g(n) + h(n) \le g(n) + c(n, a, n') + h(n')$$ $$f(n) \le g(n') + h(n') = f(n')$$
  3. Thus, $f(n)$ is monotonically non-decreasing along any path.
  4. Consequently, whenever $A^*$ selects a node $n$ for expansion from the OPEN list, the path found to $n$ is guaranteed to be optimal. No previously expanded node on the CLOSED list ever needs to be reopened, guaranteeing graph search optimality. $lacksquare$

"Explain the operation of Simulated Annealing. Detail how the cooling schedule and Boltzmann probability $P = e^{\Delta E / T}$ prevent the search from getting trapped in local maxima."

Show Complete Step-by-Step Model Answer

1. Inspiration & Algorithmic Framework:

Adapted from metallurgical annealing (gradual cooling of molten metals to reach low-energy crystalline states), Simulated Annealing escapes local maxima by combining greedy hill-climbing with stochastic exploration.

2. Downhill Move Acceptance Rule:

  • At state $s$, pick a random neighboring state $s'$. Compute energy difference $\Delta E = E(s') - E(s)$.
  • If $\Delta E > 0$ (uphill move towards improvement), the move is always accepted.
  • If $\Delta E \le 0$ (downhill move), the move is accepted probabilistically with Boltzmann probability: $$P = e^{\Delta E / T}$$ where $T > 0$ is the current temperature parameter.

3. Role of Temperature ($T$) and Cooling Schedule:

  • Initial High Temperature ($T \gg 0$): When $T$ is very large, $\Delta E / T pprox 0 \implies P pprox e^0 = 1$. The search accepts almost all downhill moves, behaving like a random walk that freely explores the entire landscape without getting trapped.
  • Cooling Progression ($T_{k+1} = lpha T_k, 0.8 \le lpha \le 0.99$): As $T$ decreases, the probability $P$ of accepting worse moves drops exponentially. The agent becomes increasingly selective, accepting only shallow downhill moves.
  • Freezing Phase ($T o 0$): As $T o 0$, $P o 0$. Downhill moves are strictly rejected, and the algorithm smoothly degenerates into standard greedy hill-climbing, locking cleanly into the nearest global peak.

PRACTICE 3 • HEURISTIC CONSISTENCY PROOF

Prove mathematically by mathematical induction that every consistent (monotonic) heuristic is necessarily admissible.

Show Step-by-Step Solution

Proof:

  1. By definition of consistency, for any state $n$ and successor $n'$ via action $a$: $$h(n) \le c(n, a, n') + h(n')$$
  2. Let $n = n_0 o n_1 o n_2 o \dots o n_k = G$ be the optimal path from node $n$ to goal $G$.
  3. Applying the consistency inequality along this optimal chain: $$h(n_0) \le c(n_0, a_1, n_1) + h(n_1)$$ $$h(n_0) \le c(n_0, a_1, n_1) + c(n_1, a_2, n_2) + h(n_2)$$ $$h(n_0) \le \sum_{i=0}^{k-1} c(n_i, a_{i+1}, n_{i+1}) + h(G)$$
  4. Since $G$ is a goal state, $h(G) = 0$.
  5. The sum of optimal step costs is by definition the true optimal cost $h^*(n_0)$: $$h(n_0) \le h^*(n_0) + 0 = h^*(n_0)$$
  6. Therefore, $h(n) \le h^*(n)$ for all nodes $n$, proving $h$ is admissible. $lacksquare$

PRACTICE 6 • UCS GOAL TEST TIMING & ZERO COSTS

Why must Uniform Cost Search apply the goal test when a node is selected for EXPANSION (popped from priority queue), rather than when it is GENERATED (inserted into queue)?

Show Step-by-Step Solution

Answer:

  • If the goal test were applied when a node is generated, UCS could stop immediately upon discovering the first path to the goal.
  • However, that first path might have a high step cost (e.g., $S o G$ with cost 10). A much cheaper path might exist (e.g., $S o A o B o G$ with total cost $1+1+1 = 3$), but its intermediate nodes have not yet been expanded!
  • By testing for the goal only when a node is popped for expansion, UCS guarantees that all nodes with path cost less than $g(G)$ have already been expanded. This ensures that when $G$ is popped, no cheaper path to $G$ can possibly exist, preserving mathematical optimality.
