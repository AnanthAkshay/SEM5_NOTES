§ 1

Context-Free Grammars (CFG)

Regular languages are incapable of counting or maintaining nested balance (such as matching parentheses or ensuring equal numbers of $a$'s and $b$'s). Context-Free Grammars (CFGs) provide the mathematical foundation for programming language syntax, compiler parsers, and nested structures.

4-TUPLE FORMAL DEFINITION OF CFG

A Context-Free Grammar is formally specified as a 4-tuple:

$$G = (V, T, P, S)$$

Where:

  • $V$: A finite set of variables (also called non-terminals or syntactic categories), conventionally denoted by uppercase letters ($A, B, S, E, T$).
  • $T$: A finite set of terminals (the actual alphabet of the generated language, disjoint from $V$, i.e., $V \cap T = \emptyset$), conventionally denoted by lowercase letters, digits, or symbols ($a, b, 0, 1, +, *$).
  • $P$: A finite set of production rules of the form: $$A \to \alpha \quad \text{where } A \in V \text{ and } \alpha \in (V \cup T)^*$$ Key property: The left-hand side contains exactly one single variable $A$ with zero surrounding context (hence "context-free").
  • $S \in V$: The designated start symbol from which all derivations begin.

Derivation Relations & Language Generated

If $A \to \gamma \in P$, and $\alpha, \beta \in (V \cup T)^*$, we say that $\alpha A \beta$ directly derives $\alpha \gamma \beta$ in one step, denoted:

$$\alpha A \beta \implies \alpha \gamma \beta$$

The reflexive-transitive closure is denoted $\implies^*$, indicating a derivation in zero or more steps.

LANGUAGE OF A GRAMMAR

The language generated by CFG $G$, denoted $L(G)$, is the set of all terminal strings derived from the start symbol $S$:

$$L(G) = \{w \in T^* \mid S \implies^* w\}$$

A string $\alpha \in (V \cup T)^*$ such that $S \implies^* \alpha$ is called a sentential form. If $\alpha \in T^*$, it is called a sentence.

QUICK RECALL
  • CFG 4-tuple: $G = (V, T, P, S)$. LHS of every production must be a single variable $A \in V$.
  • $L(G)$ consists of strings composed exclusively of terminals ($w \in T^*$).
  • Sentential forms may contain both variables and terminals; sentences contain only terminals.
§ 2

Derivations (LMD & RMD) and Parse Trees

When multiple variables appear in a sentential form, the choice of which variable to replace first gives rise to different derivation orders. However, regardless of the order, identical structural derivations correspond to the exact same parse tree.

Leftmost vs Rightmost Derivations

Derivation Type Notation Operational Rule Compiler Parallel
Leftmost Derivation (LMD) $\implies_{lm}$ At every step, replace the leftmost variable in the current sentential form. Used by top-down parsers (LL(k) parsers, recursive descent).
Rightmost Derivation (RMD) $\implies_{rm}$ At every step, replace the rightmost variable in the current sentential form. Also called canonical derivation. Used by bottom-up parsers in reverse (LR(k), LALR, shift-reduce).

Parse Trees (Derivation Trees)

FORMAL PROPERTIES OF A PARSE TREE
  1. Root Node: Labeled with the grammar's start symbol $S$.
  2. Interior Nodes: Each internal node is labeled with a variable $A \in V$.
  3. Child Nodes: If an interior node $A$ has children labeled $X_1, X_2, \dots, X_k$ from left to right, then $A \to X_1 X_2 \dots X_k$ must be a valid production in $P$.
  4. Leaf Nodes: Each leaf is labeled with a terminal symbol $a \in T$ or $\epsilon$. If labeled with $\epsilon$, it must be the only child of its parent.
  5. Yield: The concatenation of all leaf node labels read strictly from left to right forms the terminal string $w$, called the yield of the tree.
Parse Tree for Arithmetic Expression: id + id * id
QUICK RECALL
  • LMD replaces leftmost variable at each step; RMD replaces rightmost variable.
  • There is a 1-to-1 correspondence between parse trees and leftmost derivations.
  • Yield of a tree is formed by concatenating leaf labels from left to right.
§ 3

Ambiguity in Grammars and Languages

A grammar is ambiguous if it allows a single sentence to have multiple syntactic interpretations. In compilers, ambiguity is unacceptable because it leads to unpredictable execution semantics.

FORMAL DEFINITION: AMBIGUOUS GRAMMAR

A context-free grammar $G$ is called ambiguous if there exists at least one string $w \in L(G)$ that possesses:

  • Two or more distinct parse trees, OR equivalently
  • Two or more distinct leftmost derivations (LMDs), OR equivalently
  • Two or more distinct rightmost derivations (RMDs).
CLASSIC EXAM PROOF • PROVING AMBIGUITY [6 MARKS]

Prove that the grammar $E \to E + E \mid E * E \mid id$ is Ambiguous

To prove ambiguity, it is sufficient to exhibit one single string with two distinct leftmost derivations.

Witness String: Consider $w = id + id * id \in L(G)$.

Derivation 1 (Addition evaluated last, Multiplication binds first):

$$\begin{aligned} E &\implies_{lm} \mathbf{E} + E \\ &\implies_{lm} id + \mathbf{E} \\ &\implies_{lm} id + \mathbf{E} * E \\ &\implies_{lm} id + id * \mathbf{E} \\ &\implies_{lm} id + id * id \end{aligned}$$

Derivation 2 (Multiplication evaluated last, Addition binds first):

$$\begin{aligned} E &\implies_{lm} \mathbf{E} * E \\ &\implies_{lm} \mathbf{E} + E * E \\ &\implies_{lm} id + \mathbf{E} * E \\ &\implies_{lm} id + id * \mathbf{E} \\ &\implies_{lm} id + id * id \end{aligned}$$
Since string $w = id + id * id$ has two distinct leftmost derivations (and correspondingly two distinct parse trees with different operator groupings), the grammar is rigorously proved to be ambiguous.

Disambiguation Techniques

In practice, ambiguous grammars can be rewritten into equivalent unambiguous grammars using two core principles:

  1. Precedence Stratification: Introduce a distinct variable for each precedence level. Operators with higher precedence are placed further down the derivation chain (closer to the leaves).
  2. Associativity (Recursion direction):
    • For left-associative operators ($+, -, *, /$), use left recursion: $E \to E + T \mid T$.
    • For right-associative operators (e.g. exponentiation $\text{^}$ or assignment $=$), use right recursion: $E \to T \text{ ^ } E \mid T$.
INHERENT AMBIGUITY

A context-free language $L$ is said to be inherently ambiguous if every CFG that generates $L$ is ambiguous. That is, it is impossible to construct any unambiguous CFG for $L$.

Standard Example: The language $L = \{a^i b^j c^k \mid i = j \text{ or } j = k\}$. Any grammar generating $L$ must generate strings where $i = j = k$ via two inherently conflicting branches ($a^n b^n c^n$).

QUICK RECALL
  • Ambiguity = $\ge 2$ distinct parse trees or LMDs for at least one string.
  • Disambiguate expressions by introducing precedence levels ($E, T, F$) and left-recursive rules.
  • Inherent ambiguity is a property of the language, not merely a flaw in a specific grammar.
§ 4

Simplification of Context-Free Grammars

Before converting a CFG into normal forms (such as Chomsky Normal Form), the grammar must be cleansed of inefficiencies. The simplification pipeline consists of three sequential transformations that must be performed in a precise order.

MANDATORY ORDER OF PIPELINE

To eliminate all unwanted symbols cleanly, perform the three phases in this exact sequence:

1
Eliminate Null ($\epsilon$) Productions: Remove $A \to \epsilon$.
2
Eliminate Unit Productions: Remove rules of the form $A \to B$.
3
Eliminate Useless Symbols: Eliminate non-generating symbols first, then non-reachable symbols.

Phase 1: Elimination of Null Productions ($A \to \epsilon$)

A variable $A$ is nullable if $A \implies^* \epsilon$.

ALGORITHM TO REMOVE NULL PRODUCTIONS
  1. Find all nullable variables:
    • Base: If $A \to \epsilon \in P$, then $A$ is nullable.
    • Induction: If $B \to X_1 X_2 \dots X_k \in P$ and all $X_i$ are already marked nullable, then $B$ is nullable.
  2. Construct new production set $P'$: For every production $A \to Y_1 Y_2 \dots Y_m$, include all combinations where one or more nullable symbols among the $Y_i$ are omitted. Do not include $A \to \epsilon$.
  3. If the original language contained $\epsilon$ (i.e. $S$ is nullable), introduce a new start symbol $S_0$ with productions $S_0 \to S \mid \epsilon$.

Phase 2: Elimination of Unit Productions ($A \to B$)

A production is a unit production if both its left and right-hand sides are single variables ($A, B \in V$).

ALGORITHM TO REMOVE UNIT PRODUCTIONS
  1. Find all Unit Pairs: A pair $(A, B)$ is a unit pair if $A \implies^* B$ using only unit productions.
    • Base: For every $A \in V$, $(A, A)$ is a unit pair.
    • Induction: If $(A, B)$ is a unit pair and $B \to C \in P$, then $(A, C)$ is a unit pair.
  2. Construct new productions: For each unit pair $(A, B)$, if $B \to \alpha$ is a non-unit production in $P$, add $A \to \alpha$ to $P'$. Discard all unit productions $A \to B$.

Phase 3: Elimination of Useless Symbols

A symbol $X \in (V \cup T)$ is useful if there exists a derivation:

$$S \implies^* \alpha X \beta \implies^* w \quad \text{where } w \in T^*$$

To eliminate useless symbols, we must enforce two criteria in strict order:

Criterion Definition Detection Procedure
1. Generating Symbols $X$ can derive a string of terminals: $X \implies^* w, w \in T^*$ Bottom-up marking: all terminals are generating. If $A \to \alpha$ and all symbols in $\alpha$ are generating, mark $A$. Drop any symbol not marked!
2. Reachable Symbols $X$ can be reached from the start symbol: $S \implies^* \alpha X \beta$ Top-down marking: $S$ is reachable. If $A$ is reachable and $A \to X_1 \dots X_k$, then all $X_i$ are reachable. Drop all unreachable symbols.
CRITICAL EXAM TRAP: ORDER OF USELESS SYMBOL CHECKS

You MUST execute Generating first, then Reachable! Reversing this order can leave dead non-generating symbols in the grammar.

QUICK RECALL
  • Pipeline order: (1) $\epsilon$-productions $\to$ (2) Unit productions $\to$ (3) Useless symbols.
  • Nullable: symbols deriving $\epsilon$. Unit pair: $(A, B)$ where $A \implies^* B$.
  • Useless check order: (1) Generating FIRST, (2) Reachable SECOND.
§ 5

Chomsky Normal Form (CNF)

A grammar in Chomsky Normal Form (CNF) enforces a strictly binary branching structure on parse trees. In CNF, any derivation of a terminal string of length $n$ requires exactly $2n - 1$ derivation steps, which makes parsing algorithms such as the CYK algorithm possible in polynomial $O(n^3)$ time.

FORMAL DEFINITION: CHOMSKY NORMAL FORM

A CFG $G = (V, T, P, S)$ is in Chomsky Normal Form (CNF) if every production in $P$ is of one of two restricted formats:

$$A \to B C \quad \text{or} \quad A \to a$$

Where $A, B, C \in V$ (two non-terminals) and $a \in T$ (a single terminal). If $\epsilon \in L(G)$, the production $S \to \epsilon$ is permitted, provided $S$ does not appear on the right-hand side of any production.

4-STEP CONVERSION TO CNF
  1. Step 1: Simplify Grammar: Eliminate $\epsilon$-productions, eliminate unit productions, and eliminate useless symbols.
  2. Step 2: Eliminate Terminals in Mixed / Long Bodies: For every terminal $a \in T$, introduce a new variable $C_a$ and production $C_a \to a$. Replace all occurrences of $a$ in bodies of length $\ge 2$ with $C_a$. (Retain standalone $A \to a$ productions!).
  3. Step 3: Cascade Long Variable Bodies: Replace productions of length $k \ge 3$ ($A \to B_1 B_2 \dots B_k$) with a chain of binary productions: $$\begin{aligned} A &\to B_1 D_1 \\ D_1 &\to B_2 D_2 \\ &\dots \\ D_{k-2} &\to B_{k-1} B_k \end{aligned}$$
WORKED NUMERICAL • EXAM FAVOURITE [10 MARKS • STEP-BY-STEP]

Convert the following CFG into Chomsky Normal Form (CNF)

Grammar: $S \to a B \mid b A$,   $A \to a \mid a S \mid b A A$,   $B \to b \mid b S \mid a B B$

Step 1: Check Simplification:

  • $\epsilon$-productions: None exists.
  • Unit productions: None exists.
  • Useless symbols: All variables $\{S, A, B\}$ generate terminals ($A \to a, B \to b, S \to ab$) and are reachable from $S$. Grammar is already fully simplified.

Step 2: Isolate Terminals in Long Productions:

Introduce new variables $C_a \to a$ and $C_b \to b$. Replace terminals in multi-symbol right-hand sides:

  • $S \to a B \implies S \to C_a B$
  • $S \to b A \implies S \to C_b A$
  • $A \to a S \implies A \to C_a S$
  • $A \to b A A \implies A \to C_b A A$
  • $B \to b S \implies B \to C_b S$
  • $B \to a B B \implies B \to C_a B B$
  • (Retain standalone base productions $A \to a$ and $B \to b$)

Step 3: Cascade Bodies of Length 3 into Binary Rules:

  • Production $A \to C_b A A$ has length 3:
    Introduce new variable $D_1 \to A A$.
    Then $A \to C_b D_1$.
  • Production $B \to C_a B B$ has length 3:
    Introduce new variable $D_2 \to B B$.
    Then $B \to C_a D_2$.

Final Grammar in Chomsky Normal Form (CNF):

$$\begin{aligned} S &\to C_a B \mid C_b A \\ A &\to a \mid C_a S \mid C_b D_1 \\ B &\to b \mid C_b S \mid C_a D_2 \\ D_1 &\to A A \\ D_2 &\to B B \\ C_a &\to a \\ C_b &\to b \end{aligned}$$

Every single production is strictly of the form $A \to B C$ or $A \to a$. CNF conversion is complete!

QUICK RECALL
  • CNF forms: $A \to BC$ or $A \to a$.
  • Derivation of string of length $n$ takes exactly $2n - 1$ steps.
  • Parse trees in CNF are strictly binary.
§ 6

Pushdown Automata (PDA)

A Pushdown Automaton (PDA) is an extension of an $\epsilon$-NFA augmented with an infinite-capacity Last-In First-Out (LIFO) stack memory. PDAs are the exact computational recognizers for Context-Free Languages ($CFL$).

7-TUPLE FORMAL DEFINITION OF PDA

A Pushdown Automaton is formally specified by a 7-tuple:

$$M = (Q, \Sigma, \Gamma, \delta, q_0, Z_0, F)$$

Where:

  • $Q$: A finite set of states.
  • $\Sigma$: A finite set of input symbols (the input alphabet).
  • $\Gamma$: A finite set of stack symbols (the stack alphabet).
  • $\delta$: The transition function mapping: $$\delta: Q \times (\Sigma \cup \{\epsilon\}) \times \Gamma \to 2^{Q \times \Gamma^*}$$ Semantics: Given current state $q$, current input symbol $a$ (or $\epsilon$), and current top-of-stack symbol $X \in \Gamma$, $\delta(q, a, X)$ returns a set of pairs $(p, \alpha)$ where $p$ is the next state and $\alpha \in \Gamma^*$ replaces $X$ on top of the stack.
  • $q_0 \in Q$: The initial state.
  • $Z_0 \in \Gamma$: The start stack symbol (bottom-of-stack marker).
  • $F \subseteq Q$: The set of accepting (final) states.

Stack Operations via $\alpha \in \Gamma^*$

In the transition $(p, \alpha) \in \delta(q, a, X)$:

  • Pop operation: $\alpha = \epsilon$ — the top symbol $X$ is popped and discarded.
  • No-change (Read-only): $\alpha = X$ — the top symbol is read and retained.
  • Push operation: $\alpha = Y X$ — symbol $Y$ is pushed on top of $X$.
Pushdown Automaton Architectural Model

Instantaneous Descriptions (IDs)

An Instantaneous Description (ID) captures the complete global configuration of a PDA at any single computation instant as a triple:

$$(q, w, \gamma)$$

Where $q \in Q$ is the current state, $w \in \Sigma^*$ is the remaining unread input string, and $\gamma \in \Gamma^*$ is the current stack content written such that the leftmost character represents the top of stack.

The single-step transition is written $(q, aw, X\beta) \vdash (p, w, \alpha\beta)$ where $(p, \alpha) \in \delta(q, a, X)$.

Two Acceptance Mechanisms

Acceptance Criterion Formal Definition Conditions at Halt
1. By Final State: $L(M)$ $L(M) = \{w \in \Sigma^* \mid (q_0, w, Z_0) \vdash^* (q, \epsilon, \gamma) \text{ where } q \in F\}$ Input is completely consumed ($w = \epsilon$) and machine is in an accepting state $q \in F$. Stack content $\gamma$ is irrelevant!
2. By Empty Stack: $N(M)$ $N(M) = \{w \in \Sigma^* \mid (q_0, w, Z_0) \vdash^* (q, \epsilon, \epsilon) \text{ for any } q \in Q\}$ Input is completely consumed ($w = \epsilon$) and stack is completely empty ($\gamma = \epsilon$). Final state set $F$ is not required ($F = \emptyset$).
EQUIVALENCE OF ACCEPTANCE CRITERIA

For any language $L$, the following are equivalent:

  1. $L = L(M_1)$ for some PDA $M_1$ accepting by final state.
  2. $L = N(M_2)$ for some PDA $M_2$ accepting by empty stack.
  3. $L = L(G)$ for some Context-Free Grammar $G$.
QUICK RECALL
  • PDA is a 7-tuple: $(Q, \Sigma, \Gamma, \delta, q_0, Z_0, F)$.
  • ID format: $(q, w, \gamma)$ where leftmost symbol of $\gamma$ is the top of stack.
  • Acceptance by final state $L(M)$ and by empty stack $N(M)$ are mathematically equivalent.
§ 7

DPDA vs NPDA & Worked PDA Designs

Unlike finite automata (where DFA and NFA are computationally equivalent), Deterministic Pushdown Automata (DPDA) are strictly less powerful than Nondeterministic Pushdown Automata (NPDA).

DETERMINISTIC PDA (DPDA) CONDITIONS

A PDA $M = (Q, \Sigma, \Gamma, \delta, q_0, Z_0, F)$ is deterministic if and only if for all $q \in Q, a \in \Sigma$, and $X \in \Gamma$:

  1. $|\delta(q, a, X)| \le 1$ and $|\delta(q, \epsilon, X)| \le 1$ (at most one transition choice).
  2. If $\delta(q, \epsilon, X)$ is non-empty, then $\delta(q, a, X)$ must be empty for all $a \in \Sigma$ (no choice between reading a symbol and making an $\epsilon$-transition on the same stack top).

Hierarchy of Language Classes:

$$Regular \subsetneq Deterministic\ CFL\ (DCFL) \subsetneq Context\text{-}Free\ (CFL)$$

Example: $L = \{w c w^R \mid w \in \{0, 1\}^*\}$ has a marker $c$ that signals the middle of the string, so it can be recognized by a DPDA. However, $L = \{w w^R \mid w \in \{0, 1\}^*\}$ has no center marker; the machine must "guess" when the midpoint is reached, requiring an NPDA.

WORKED DESIGN 1 • VERIFIED PYTHON PASS [10 MARKS • CORE EXAM]

Design a PDA for $L = \{a^n b^n \mid n \ge 1\}$ (Acceptance by Final State)

Specification: $Q = \{q_0, q_1, q_2\}$, $\Sigma = \{a, b\}$, $\Gamma = \{Z_0, A\}$, Start $= q_0$, Stack start $= Z_0$, Final states $F = \{q_2\}$.

Transition Function $\delta$:

Rule # Current State Input Symbol Stack Top Next State Stack Replacement Operational Action
1 $q_0$ $a$ $Z_0$ $q_0$ $A Z_0$ Push first $A$ onto stack
2 $q_0$ $a$ $A$ $q_0$ $A A$ Push subsequent $A$'s
3 $q_0$ $b$ $A$ $q_1$ $\epsilon$ First $b$ matches top $A$, pop and switch to $q_1$
4 $q_1$ $b$ $A$ $q_1$ $\epsilon$ Subsequent $b$'s pop matching $A$'s
5 $q_1$ $\epsilon$ $Z_0$ $q_2$ $Z_0$ Input consumed, all $A$'s matched; move to final state $q_2$

Step-by-step Instantaneous Description (ID) Trace for $w = aabb$:

$$\begin{aligned} (q_0, aabb, Z_0) &\vdash (q_0, abb, AZ_0) \quad &[\text{Rule 1: push } A] \\ &\vdash (q_0, bb, AAZ_0) \quad &[\text{Rule 2: push } A] \\ &\vdash (q_1, b, AZ_0) \quad &[\text{Rule 3: match } b \text{ with } A\text{, pop } A] \\ &\vdash (q_1, \epsilon, Z_0) \quad &[\text{Rule 4: match } b \text{ with } A\text{, pop } A] \\ &\vdash (q_2, \epsilon, Z_0) \quad &[\text{Rule 5: move to accept state } q_2] \end{aligned}$$
The input $aabb$ is fully consumed and the PDA halts in $q_2 \in F$. Therefore, $aabb$ is accepted!
WORKED DESIGN 2 • DPDA PALINDROME [10 MARKS]

Design a DPDA for $L = \{w c w^R \mid w \in \{0, 1\}^*\}$

Idea: Push all symbols of $w$ onto the stack while in state $q_0$. When the center marker $c$ is read, transition to state $q_1$ without altering the stack. In state $q_1$, pop matching symbols for $w^R$. Upon seeing $Z_0$, enter final state $q_2$.

Phase Transitions $\delta(q, a, X) = (p, \alpha)$
Phase 1: Push $w$ $\delta(q_0, 0, Z_0) = (q_0, 0 Z_0)$,   $\delta(q_0, 1, Z_0) = (q_0, 1 Z_0)$
$\delta(q_0, 0, 0) = (q_0, 0 0)$,   $\delta(q_0, 0, 1) = (q_0, 0 1)$
$\delta(q_0, 1, 0) = (q_0, 1 0)$,   $\delta(q_0, 1, 1) = (q_0, 1 1)$
Phase 2: Center Marker $c$ $\delta(q_0, c, 0) = (q_1, 0)$,   $\delta(q_0, c, 1) = (q_1, 1)$,   $\delta(q_0, c, Z_0) = (q_1, Z_0)$
Phase 3: Match $w^R$ $\delta(q_1, 0, 0) = (q_1, \epsilon)$ (pop matching 0)
$\delta(q_1, 1, 1) = (q_1, \epsilon)$ (pop matching 1)
Phase 4: Accept $\delta(q_1, \epsilon, Z_0) = (q_2, Z_0)$ (enter final state $q_2 \in F$)

2-Mark Questions (Short Answer)

2M Define a Context-Free Grammar (CFG).

Answer: A CFG is a 4-tuple $G = (V, T, P, S)$ where $V$ is a finite set of variables, $T$ is a finite set of terminals disjoint from $V$, $P$ is a set of productions of the form $A \to \alpha$ with $A \in V$ and $\alpha \in (V \cup T)^*$, and $S \in V$ is the start symbol.

2M Distinguish between LMD and RMD with an example.

Answer: In a Leftmost Derivation (LMD), the leftmost variable in the sentential form is replaced at every step. In a Rightmost Derivation (RMD), the rightmost variable is replaced at every step. Both yield the exact same sentence and parse tree.

2M What is Chomsky Normal Form (CNF)?

Answer: A CFG is in CNF if every production is of the form $A \to BC$ (two variables) or $A \to a$ (one terminal), plus optionally $S \to \epsilon$ if $\epsilon \in L(G)$.

5-Mark Questions (Medium Length)

5M Explain the process of eliminating $\epsilon$-productions from a CFG.

Answer:

  1. Find all nullable variables (variables $A$ where $A \implies^* \epsilon$).
  2. For every production $A \to X_1 X_2 \dots X_k$, form new productions by considering all possible combinations where nullable variables are either included or replaced by $\epsilon$.
  3. Discard all $A \to \epsilon$ productions.
  4. If $S$ is nullable, introduce a new start symbol $S_0 \to S \mid \epsilon$.
5M Compare acceptance by final state vs acceptance by empty stack in PDA.

Answer:

  • Final State $L(M)$: The input string is accepted if after reading the entire input, the PDA is in any state $q \in F$. Stack content does not matter.
  • Empty Stack $N(M)$: The input string is accepted if after reading the entire input, the stack is completely empty ($\epsilon$). The final state set is not needed ($F = \emptyset$).
  • Both models are equivalent in power: any PDA accepting by empty stack can be converted into an equivalent PDA accepting by final state and vice versa.

10-Mark Questions (Long Answer / Comprehensive)

10M Define a PDA. Design a PDA for $L = \{w w^R \mid w \in \{a, b\}^*\}$ and explain its operation.

Answer Summary:

1. State the 7-tuple definition: $M = (Q, \Sigma, \Gamma, \delta, q_0, Z_0, F)$.

2. Explain the necessity of nondeterminism: because the string has no center marker, the PDA cannot deterministically know when the first half $w$ ends and the reverse half $w^R$ begins. It must nondeterministically guess the center.

3. Transitions: In state $q_0$, push $a$ and $b$ symbols. Add nondeterministic $\epsilon$-transitions $\delta(q_0, \epsilon, X) = \{(q_1, X)\}$ to guess the midpoint. In state $q_1$, match input against stack top and pop. When $Z_0$ is encountered, enter final state $q_2 \in F$.

Ramaiah Internal Assessment - II (Dec 2025) • Q 2(a) [5 Marks • Blooms L3, CO3]

"Define Nullable symbol. Eliminate ε-production from the given grammar: S → ASA | aBbA, A → B | BaA, B → b | ε."

Definition: A non-terminal symbol $X$ is called nullable if $X \Rightarrow^* \epsilon$ (it can derive the empty string in one or more derivation steps).

Step 1: Identify all Nullable Variables:

  • $B \to \epsilon \implies B$ is nullable.
  • $A \to B$ where $B$ is nullable $\implies A$ is nullable.
  • $S \to ASA$ where both $A$ and $S$ appear: since $A$ is nullable, $S \to ASA \implies S \to \epsilon$ if $S$ is nullable.
  • Set of Nullable Variables: $\mathbf{\{B, A, S\}}$.

Step 2: Eliminate $\epsilon$-productions by systematic substitution:

  • From $B \to b \mid \epsilon$: Drop $\epsilon \implies \mathbf{B \to b}$.
  • From $A \to B \mid BaA$: Substitute nullable $B$ and $A$:
    • From $A \to B$: $A \to B \mid \epsilon$ (drop $\epsilon$) $\implies \mathbf{A \to B}$.
    • From $A \to BaA$: $B$ present or absent, $A$ present or absent $\implies \mathbf{A \to BaA \mid aA \mid Ba \mid a}$.
    • Combined for $A$: $\mathbf{A \to B \mid BaA \mid aA \mid Ba \mid a}$.
  • From $S \to ASA \mid aBbA$:
    • From $S \to ASA$: $S \to ASA \mid SA \mid AS \mid S \mid AA \mid A$ (remove $S \to S$).
    • From $S \to aBbA$: $B$ present or absent $\implies S \to aBbA \mid abA$.
    • Combined for $S$: $\mathbf{S \to ASA \mid SA \mid AS \mid AA \mid A \mid aBbA \mid abA}$.

Final Grammar without $\epsilon$-productions:

$$S \to ASA \mid SA \mid AS \mid AA \mid A \mid aBbA \mid abA$$ $$A \to B \mid BaA \mid aA \mid Ba \mid a$$ $$B \to b$$

"Is the following grammar ambiguous? S → aB | bA, A → aS | bAA | a, B → bS | aBB | b. Justify with proof."

Theorem: A context-free grammar $G$ is ambiguous if there exists at least one string $w \in L(G)$ that admits two or more distinct leftmost derivations (LMDs) or two distinct parse trees.

Consider the terminal string $\mathbf{w = abab} \in L(G)$:

1. $S \implies aB$
2. $\implies a(bS) = abS$
3. $\implies ab(aB) = abaB$
4. $\implies aba(b) = \mathbf{abab}$ 		1. $S \implies aB$
2. $\implies a(aBB) = aaBB$

PRACTICE 1 • CFG DESIGN

Design a context-free grammar for the language $L = \{a^n b^{2n} \mid n \ge 1\}$ (twice as many b's as a's).

Show Step-by-Step Solution

For every single terminal $a$ placed on the left, exactly two terminal $b$'s must be placed on the right:

$$\mathbf{S \to a S b b \mid a b b}$$

Trace for n = 2 ($a^2 b^4 = aabbbb$):

$$S \implies a S b b \implies a (a b b) b b = \mathbf{a a b b b b}$$
PRACTICE 2 • UNIT PRODUCTION REMOVAL

Eliminate unit productions from grammar: $S \to A \mid bb, \quad A \to B \mid b, \quad B \to S \mid a$.

Show Step-by-Step Solution

Step 1: Compute Unit Pairs $(A, B)$ where $A \Rightarrow^* B$:

  • From $S$: $(S, A), (S, B)$ (since $S \to A \to B \to S$, cycle $\{S, A, B\}$!)
  • From $A$: $(A, B), (A, S)$
  • From $B$: $(B, S), (B, A)$

Step 2: Collect all non-unit productions:

Non-unit productions in grammar: $S \to bb$, $A \to b$, $B \to a$.

Step 3: Assign all non-unit productions to all equivalent variables:

$$\mathbf{S \to bb \mid b \mid a}$$ $$\mathbf{A \to bb \mid b \mid a}$$ $$\mathbf{B \to bb \mid b \mid a}$$
PRACTICE 3 • CHOMSKY NORMAL FORM

Convert the grammar $S \to a A b \mid a B, \quad A \to b A \mid b, \quad B \to a$ into Chomsky Normal Form (CNF).

Show Step-by-Step Solution

Step 1: Introduce terminal variables: $T_a \to a$, $T_b \to b$.

Substitute terminals: $S \to T_a A T_b \mid T_a B$, $A \to T_b A \mid b$, $B \to a$.

Step 2: Break long right-hand sides ($\ge 3$ symbols):

Production $S \to T_a A T_b$ has 3 variables. Introduce $X_1 \to A T_b$. Then $S \to T_a X_1$.

Final CNF Grammar:

$$\mathbf{S \to T_a X_1 \mid T_a B}$$ $$\mathbf{X_1 \to A T_b}$$ $$\mathbf{A \to T_b A \mid b}$$ $$\mathbf{B \to a}$$ $$\mathbf{T_a \to a, \quad T_b \to b}$$
PRACTICE 4 • DPDA PALINDROME MARKER

Why does the language $L = \{w c w^R \mid w \in \{a, b\}^*\}$ admit a Deterministic PDA (DPDA), while $L = \{w w^R\}$ strictly requires an NPDA?

Show Step-by-Step Solution

In $L = \{w c w^R\}$, the marker $c \notin \{a, b\}$ provides an unambiguous, deterministic boundary. The automaton pushes symbols in state $q_0$ until reading $c$, which triggers an immediate, deterministic state transition to $q_1$ where it matches and pops.

In contrast, $L = \{w w^R\}$ has no marker. For string $w = aaaa$, the midpoint could be after 1, 2, or 3 symbols. A deterministic machine cannot decide when to stop pushing and start popping without backtracking. Thus, non-determinism is strictly mandatory.

PRACTICE 5 • EMPTY STACK VS FINAL STATE

Explain the standard construction for converting a PDA that accepts by Empty Stack $N(M)$ to an equivalent PDA that accepts by Final State $L(M')$.

Show Step-by-Step Solution
  1. Create new initial state $q_0'$ and new bottom stack marker $X_0 \notin \Gamma$.
  2. Add transition $\delta'(q_0', \epsilon, X_0) = \{(q_0, Z_0 X_0)\}$ to place the original stack marker $Z_0$ above $X_0$ and transition to $q_0$.
  3. Whenever original machine $M$ empties its stack, only $X_0$ remains.
  4. Add transition $\delta'(q, \epsilon, X_0) = \{(q_f, \epsilon)\}$ for all states $q \in Q$ to enter new unique final accept state $q_f \in F'$.
PRACTICE 6 • PUMPING LEMMA FOR CFL

State the Pumping Lemma for Context-Free Languages (CFL) and define all 5 conditions for $s = u v w x y$.

Show Step-by-Step Solution

If $L$ is context-free, there exists pumping length $p$ such that any $s \in L$ with $|s| \ge p$ can be divided into $s = u v w x y$ satisfying:

  1. $|v x| \ge 1$ (at least one of $v$ or $x$ is non-empty)
  2. $|v w x| \le p$ (the pumped substring has length at most $p$)
  3. $\forall i \ge 0, \quad u v^i w x^i y \in L$ (both pieces $v$ and $x$ pump simultaneously)
