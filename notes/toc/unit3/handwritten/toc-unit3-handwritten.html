Context-Free Grammars (CFG)

§ 1

Regular languages are incapable of counting or maintaining nested balance (such as matching parentheses or ensuring equal numbers of aaa's and bbb's). Context-Free Grammars (CFGs) provide the mathematical foundation for programming language syntax, compiler parsers, and nested structures.

4-TUPLE FORMAL DEFINITION OF CFG

A Context-Free Grammar is formally specified as a 4-tuple:

G=(V,T,P,S)G = (V, T, P, S)G=(V,T,P,S)

Where:

  • VVV: A finite set of variables (also called non-terminals or syntactic categories), conventionally denoted by uppercase letters (A,B,S,E,TA, B, S, E, TA,B,S,E,T).
  • TTT: A finite set of terminals (the actual alphabet of the generated language, disjoint from VVV, i.e., V∩T=∅V \cap T = \emptysetV∩T=∅), conventionally denoted by lowercase letters, digits, or symbols (a,b,0,1,+,∗a, b, 0, 1, +, *a,b,0,1,+,∗).
  • PPP: A finite set of production rules of the form: A→αwhere A∈V and α∈(V∪T)∗A \to \alpha \quad \text{where } A \in V \text{ and } \alpha \in (V \cup T)^*A→αwhere A∈V and α∈(V∪T)∗ Key property: The left-hand side contains exactly one single variable AAA with zero surrounding context (hence "context-free").
  • S∈VS \in VS∈V: The designated start symbol from which all derivations begin.

Derivation Relations & Language Generated

If A→γ∈PA \to \gamma \in PA→γ∈P, and α,β∈(V∪T)∗\alpha, \beta \in (V \cup T)^*α,β∈(V∪T)∗, we say that αAβ\alpha A \betaαAβ directly derives αγβ\alpha \gamma \betaαγβ in one step, denoted:

αAβ  ⟹  αγβ\alpha A \beta \implies \alpha \gamma \betaαAβ⟹αγβ

The reflexive-transitive closure is denoted   ⟹  ∗\implies^*⟹∗, indicating a derivation in zero or more steps.

LANGUAGE OF A GRAMMAR

The language generated by CFG GGG, denoted L(G)L(G)L(G), is the set of all terminal strings derived from the start symbol SSS:

L(G)={w∈T∗∣S  ⟹  ∗w}L(G) = \{w \in T^* \mid S \implies^* w\}L(G)={w∈T∗∣S⟹∗w}

A string α∈(V∪T)∗\alpha \in (V \cup T)^*α∈(V∪T)∗ such that S  ⟹  ∗αS \implies^* \alphaS⟹∗α is called a sentential form. If α∈T∗\alpha \in T^*α∈T∗, it is called a sentence.

QUICK RECALL
  • CFG 4-tuple: G=(V,T,P,S)G = (V, T, P, S)G=(V,T,P,S). LHS of every production must be a single variable A∈VA \in VA∈V.
  • L(G)L(G)L(G) consists of strings composed exclusively of terminals (w∈T∗w \in T^*w∈T∗).
  • Sentential forms may contain both variables and terminals; sentences contain only terminals.

Derivations (LMD & RMD) and Parse Trees

§ 2

When multiple variables appear in a sentential form, the choice of which variable to replace first gives rise to different derivation orders. However, regardless of the order, identical structural derivations correspond to the exact same parse tree.

Leftmost vs Rightmost Derivations

Derivation Type Notation Operational Rule Compiler Parallel
Leftmost Derivation (LMD)   ⟹  lm\implies_{lm}⟹lm​ At every step, replace the leftmost variable in the current sentential form. Used by top-down parsers (LL(k) parsers, recursive descent).
Rightmost Derivation (RMD)   ⟹  rm\implies_{rm}⟹rm​ At every step, replace the rightmost variable in the current sentential form. Also called canonical derivation. Used by bottom-up parsers in reverse (LR(k), LALR, shift-reduce).

Parse Trees (Derivation Trees)

FORMAL PROPERTIES OF A PARSE TREE
  1. Root Node: Labeled with the grammar's start symbol SSS.
  2. Interior Nodes: Each internal node is labeled with a variable A∈VA \in VA∈V.
  3. Child Nodes: If an interior node AAA has children labeled X1,X2,…,XkX_1, X_2, \dots, X_kX1​,X2​,…,Xk​ from left to right, then A→X1X2…XkA \to X_1 X_2 \dots X_kA→X1​X2​…Xk​ must be a valid production in PPP.
  4. Leaf Nodes: Each leaf is labeled with a terminal symbol a∈Ta \in Ta∈T or ϵ\epsilonϵ. If labeled with ϵ\epsilonϵ, it must be the only child of its parent.
  5. Yield: The concatenation of all leaf node labels read strictly from left to right forms the terminal string www, called the yield of the tree.
Parse Tree for Arithmetic Expression: id + id * id
QUICK RECALL
  • LMD replaces leftmost variable at each step; RMD replaces rightmost variable.
  • There is a 1-to-1 correspondence between parse trees and leftmost derivations.
  • Yield of a tree is formed by concatenating leaf labels from left to right.

Ambiguity in Grammars and Languages

§ 3

A grammar is ambiguous if it allows a single sentence to have multiple syntactic interpretations. In compilers, ambiguity is unacceptable because it leads to unpredictable execution semantics.

FORMAL DEFINITION: AMBIGUOUS GRAMMAR

A context-free grammar GGG is called ambiguous if there exists at least one string w∈L(G)w \in L(G)w∈L(G) that possesses:

  • Two or more distinct parse trees, OR equivalently
  • Two or more distinct leftmost derivations (LMDs), OR equivalently
  • Two or more distinct rightmost derivations (RMDs).
CLASSIC EXAM PROOF • PROVING AMBIGUITY [6 MARKS]

Prove that the grammar E→E+E∣E∗E∣idE \to E + E \mid E * E \mid idE→E+E∣E∗E∣id is Ambiguous

To prove ambiguity, it is sufficient to exhibit one single string with two distinct leftmost derivations.

Witness String: Consider w=id+id∗id∈L(G)w = id + id * id \in L(G)w=id+id∗id∈L(G).

Derivation 1 (Addition evaluated last, Multiplication binds first):

E  ⟹  lmE+E  ⟹  lmid+E  ⟹  lmid+E∗E  ⟹  lmid+id∗E  ⟹  lmid+id∗id\begin{aligned} E &\implies_{lm} \mathbf{E} + E \\ &\implies_{lm} id + \mathbf{E} \\ &\implies_{lm} id + \mathbf{E} * E \\ &\implies_{lm} id + id * \mathbf{E} \\ &\implies_{lm} id + id * id \end{aligned}E​⟹lm​E+E⟹lm​id+E⟹lm​id+E∗E⟹lm​id+id∗E⟹lm​id+id∗id​

E  ⟹  lmE∗E  ⟹  lmE+E∗E  ⟹  lmid+E∗E  ⟹  lmid+id∗E  ⟹  lmid+id∗id\begin{aligned} E &\implies_{lm} \mathbf{E} * E \\ &\implies_{lm} \mathbf{E} + E * E \\ &\implies_{lm} id + \mathbf{E} * E \\ &\implies_{lm} id + id * \mathbf{E} \\ &\implies_{lm} id + id * id \end{aligned}E​⟹lm​E∗E⟹lm​E+E∗E⟹lm​id+E∗E⟹lm​id+id∗E⟹lm​id+id∗id​
Since string w=id+id∗idw = id + id * idw=id+id∗id has two distinct leftmost derivations (and correspondingly two distinct parse trees with different operator groupings), the grammar is rigorously proved to be ambiguous.

Disambiguation Techniques

In practice, ambiguous grammars can be rewritten into equivalent unambiguous grammars using two core principles:

  1. Precedence Stratification: Introduce a distinct variable for each precedence level. Operators with higher precedence are placed further down the derivation chain (closer to the leaves).
  2. Associativity (Recursion direction):
    • For left-associative operators (+,−,∗,/+, -, *, /+,−,∗,/), use left recursion: E→E+T∣TE \to E + T \mid TE→E+T∣T.
    • For right-associative operators (e.g. exponentiation \text{^} or assignment ===), use right recursion: E \to T \text{ ^ } E \mid T.
INHERENT AMBIGUITY

A context-free language LLL is said to be inherently ambiguous if every CFG that generates LLL is ambiguous. That is, it is impossible to construct any unambiguous CFG for LLL.

Standard Example: The language L={aibjck∣i=j or j=k}L = \{a^i b^j c^k \mid i = j \text{ or } j = k\}L={aibjck∣i=j or j=k}. Any grammar generating LLL must generate strings where i=j=ki = j = ki=j=k via two inherently conflicting branches (anbncna^n b^n c^nanbncn).

QUICK RECALL
  • Ambiguity = ≥2\ge 2≥2 distinct parse trees or LMDs for at least one string.
  • Disambiguate expressions by introducing precedence levels (E,T,FE, T, FE,T,F) and left-recursive rules.
  • Inherent ambiguity is a property of the language, not merely a flaw in a specific grammar.

Simplification of Context-Free Grammars

§ 4

Before converting a CFG into normal forms (such as Chomsky Normal Form), the grammar must be cleansed of inefficiencies. The simplification pipeline consists of three sequential transformations that must be performed in a precise order.

MANDATORY ORDER OF PIPELINE

To eliminate all unwanted symbols cleanly, perform the three phases in this exact sequence:

1
Eliminate Null (ϵ\epsilonϵ) Productions: Remove A→ϵA \to \epsilonA→ϵ.
2
Eliminate Unit Productions: Remove rules of the form A→BA \to BA→B.
3
Eliminate Useless Symbols: Eliminate non-generating symbols first, then non-reachable symbols.

Phase 1: Elimination of Null Productions (A→ϵA \to \epsilonA→ϵ)

A variable AAA is nullable if A  ⟹  ∗ϵA \implies^* \epsilonA⟹∗ϵ.

ALGORITHM TO REMOVE NULL PRODUCTIONS
  1. Find all nullable variables:
    • Base: If A→ϵ∈PA \to \epsilon \in PA→ϵ∈P, then AAA is nullable.
    • Induction: If B→X1X2…Xk∈PB \to X_1 X_2 \dots X_k \in PB→X1​X2​…Xk​∈P and all XiX_iXi​ are already marked nullable, then BBB is nullable.
  2. Construct new production set P′P'P′: For every production A→Y1Y2…YmA \to Y_1 Y_2 \dots Y_mA→Y1​Y2​…Ym​, include all combinations where one or more nullable symbols among the YiY_iYi​ are omitted. Do not include A→ϵA \to \epsilonA→ϵ.
  3. If the original language contained ϵ\epsilonϵ (i.e. SSS is nullable), introduce a new start symbol S0S_0S0​ with productions S0→S∣ϵS_0 \to S \mid \epsilonS0​→S∣ϵ.

Phase 2: Elimination of Unit Productions (A→BA \to BA→B)

A production is a unit production if both its left and right-hand sides are single variables (A,B∈VA, B \in VA,B∈V).

ALGORITHM TO REMOVE UNIT PRODUCTIONS
  1. Find all Unit Pairs: A pair (A,B)(A, B)(A,B) is a unit pair if A  ⟹  ∗BA \implies^* BA⟹∗B using only unit productions.
    • Base: For every A∈VA \in VA∈V, (A,A)(A, A)(A,A) is a unit pair.
    • Induction: If (A,B)(A, B)(A,B) is a unit pair and B→C∈PB \to C \in PB→C∈P, then (A,C)(A, C)(A,C) is a unit pair.
  2. Construct new productions: For each unit pair (A,B)(A, B)(A,B), if B→αB \to \alphaB→α is a non-unit production in PPP, add A→αA \to \alphaA→α to P′P'P′. Discard all unit productions A→BA \to BA→B.

Phase 3: Elimination of Useless Symbols

A symbol X∈(V∪T)X \in (V \cup T)X∈(V∪T) is useful if there exists a derivation:

S  ⟹  ∗αXβ  ⟹  ∗wwhere w∈T∗S \implies^* \alpha X \beta \implies^* w \quad \text{where } w \in T^*S⟹∗αXβ⟹∗wwhere w∈T∗

To eliminate useless symbols, we must enforce two criteria in strict order:

Criterion Definition Detection Procedure
1. Generating Symbols XXX can derive a string of terminals: X  ⟹  ∗w,w∈T∗X \implies^* w, w \in T^*X⟹∗w,w∈T∗ Bottom-up marking: all terminals are generating. If A→αA \to \alphaA→α and all symbols in α\alphaα are generating, mark AAA. Drop any symbol not marked!
2. Reachable Symbols XXX can be reached from the start symbol: S  ⟹  ∗αXβS \implies^* \alpha X \betaS⟹∗αXβ Top-down marking: SSS is reachable. If AAA is reachable and A→X1…XkA \to X_1 \dots X_kA→X1​…Xk​, then all XiX_iXi​ are reachable. Drop all unreachable symbols.
CRITICAL EXAM TRAP: ORDER OF USELESS SYMBOL CHECKS

You MUST execute Generating first, then Reachable! Reversing this order can leave dead non-generating symbols in the grammar.

QUICK RECALL
  • Pipeline order: (1) ϵ\epsilonϵ-productions →\to→ (2) Unit productions →\to→ (3) Useless symbols.
  • Nullable: symbols deriving ϵ\epsilonϵ. Unit pair: (A,B)(A, B)(A,B) where A  ⟹  ∗BA \implies^* BA⟹∗B.
  • Useless check order: (1) Generating FIRST, (2) Reachable SECOND.

Chomsky Normal Form (CNF)

§ 5

A grammar in Chomsky Normal Form (CNF) enforces a strictly binary branching structure on parse trees. In CNF, any derivation of a terminal string of length nnn requires exactly 2n−12n - 12n−1 derivation steps, which makes parsing algorithms such as the CYK algorithm possible in polynomial O(n3)O(n^3)O(n3) time.

FORMAL DEFINITION: CHOMSKY NORMAL FORM

A CFG G=(V,T,P,S)G = (V, T, P, S)G=(V,T,P,S) is in Chomsky Normal Form (CNF) if every production in PPP is of one of two restricted formats:

A→BCorA→aA \to B C \quad \text{or} \quad A \to aA→BCorA→a

Where A,B,C∈VA, B, C \in VA,B,C∈V (two non-terminals) and a∈Ta \in Ta∈T (a single terminal). If ϵ∈L(G)\epsilon \in L(G)ϵ∈L(G), the production S→ϵS \to \epsilonS→ϵ is permitted, provided SSS does not appear on the right-hand side of any production.

4-STEP CONVERSION TO CNF
  1. Step 1: Simplify Grammar: Eliminate ϵ\epsilonϵ-productions, eliminate unit productions, and eliminate useless symbols.
  2. Step 2: Eliminate Terminals in Mixed / Long Bodies: For every terminal a∈Ta \in Ta∈T, introduce a new variable CaC_aCa​ and production Ca→aC_a \to aCa​→a. Replace all occurrences of aaa in bodies of length ≥2\ge 2≥2 with CaC_aCa​. (Retain standalone A→aA \to aA→a productions!).

Pushdown Automata (PDA)

§ 6

A Pushdown Automaton (PDA) is an extension of an ϵ\epsilonϵ-NFA augmented with an infinite-capacity Last-In First-Out (LIFO) stack memory. PDAs are the exact computational recognizers for Context-Free Languages (CFLCFLCFL).

7-TUPLE FORMAL DEFINITION OF PDA

A Pushdown Automaton is formally specified by a 7-tuple:

M=(Q,Σ,Γ,δ,q0,Z0,F)M = (Q, \Sigma, \Gamma, \delta, q_0, Z_0, F)M=(Q,Σ,Γ,δ,q0​,Z0​,F)

Where:

  • QQQ: A finite set of states.
  • Σ\SigmaΣ: A finite set of input symbols (the input alphabet).
  • Γ\GammaΓ: A finite set of stack symbols (the stack alphabet).
  • δ\deltaδ: The transition function mapping: δ:Q×(Σ∪{ϵ})×Γ→2Q×Γ∗\delta: Q \times (\Sigma \cup \{\epsilon\}) \times \Gamma \to 2^{Q \times \Gamma^*}δ:Q×(Σ∪{ϵ})×Γ→2Q×Γ∗ Semantics: Given current state qqq, current input symbol aaa (or ϵ\epsilonϵ), and current top-of-stack symbol X∈ΓX \in \GammaX∈Γ, δ(q,a,X)\delta(q, a, X)δ(q,a,X) returns a set of pairs (p,α)(p, \alpha)(p,α) where ppp is the next state and α∈Γ∗\alpha \in \Gamma^*α∈Γ∗ replaces XXX on top of the stack.
  • q0∈Qq_0 \in Qq0​∈Q: The initial state.
  • Z0∈ΓZ_0 \in \GammaZ0​∈Γ: The start stack symbol (bottom-of-stack marker).
  • F⊆QF \subseteq QF⊆Q: The set of accepting (final) states.

Stack Operations via α∈Γ∗\alpha \in \Gamma^*α∈Γ∗

In the transition (p,α)∈δ(q,a,X)(p, \alpha) \in \delta(q, a, X)(p,α)∈δ(q,a,X):

  • Pop operation: α=ϵ\alpha = \epsilonα=ϵ — the top symbol XXX is popped and discarded.

DPDA vs NPDA & Worked PDA Designs

§ 7

Unlike finite automata (where DFA and NFA are computationally equivalent), Deterministic Pushdown Automata (DPDA) are strictly less powerful than Nondeterministic Pushdown Automata (NPDA).

DETERMINISTIC PDA (DPDA) CONDITIONS

A PDA M=(Q,Σ,Γ,δ,q0,Z0,F)M = (Q, \Sigma, \Gamma, \delta, q_0, Z_0, F)M=(Q,Σ,Γ,δ,q0​,Z0​,F) is deterministic if and only if for all q∈Q,a∈Σq \in Q, a \in \Sigmaq∈Q,a∈Σ, and X∈ΓX \in \GammaX∈Γ:

  1. ∣δ(q,a,X)∣≤1|\delta(q, a, X)| \le 1∣δ(q,a,X)∣≤1 and ∣δ(q,ϵ,X)∣≤1|\delta(q, \epsilon, X)| \le 1∣δ(q,ϵ,X)∣≤1 (at most one transition choice).
