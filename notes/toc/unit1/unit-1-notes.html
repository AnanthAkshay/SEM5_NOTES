§ 1

Central Concepts of Automata Theory

Automata theory mathematically models abstract computing machines that process discrete input sequences according to rigorous state transitions.

Core Definitions: Alphabet, String, and Language

1. Alphabet ($\Sigma$): A finite, non-empty set of symbols. $$\text{Examples: } \Sigma = \{0, 1\} \text{ (binary)}, \quad \Sigma = \{a, b, c\}, \quad \Sigma = \text{ASCII}$$ 2. String (Word, $w$): A finite sequence of symbols chosen from an alphabet $\Sigma$.

  • Length of a string ($|w|$): The number of symbol positions in $w$ (e.g., if $w = 01011$, $|w| = 5$).
  • Empty String ($\epsilon$ or $\Lambda$): The unique string of length zero: $|\epsilon| = 0$.
  • Powers of an Alphabet ($\Sigma^k$): The set of all strings of length $k$. $\Sigma^0 = \{\epsilon\}$.
  • Kleene Star ($\Sigma^*$): The set of all strings of all possible lengths over $\Sigma$, including $\epsilon$: $$\Sigma^* = \Sigma^0 \cup \Sigma^1 \cup \Sigma^2 \cup \dots = \bigcup_{k=0}^\infty \Sigma^k$$
  • Positive Closure ($\Sigma^+$): The set of all non-empty strings: $\Sigma^+ = \Sigma^* \setminus \{\epsilon\}$.
3. Language ($L$): Any subset of strings over an alphabet: $L \subseteq \Sigma^*$. A language may be finite (e.g., $L = \{0, 01, 11\}$) or infinite (e.g., $L = \{a^n b^n \mid n \ge 1\}$).

Quick Recall

$\Sigma$ is an alphabet; $w$ is a string of length $|w|$; $\epsilon$ has length 0; $\Sigma^*$ contains all finite strings including $\epsilon$; a language $L$ is any subset $L \subseteq \Sigma^*$.

§ 2

Deterministic Finite Automata (DFA)

A Deterministic Finite Automaton (DFA) is a state machine in which for each state and for every input symbol, there is exactly one unique transition to a next state.

Formal 5-Tuple Definition of a DFA

A DFA is mathematically formalized as a 5-tuple: $$M = (Q, \Sigma, \delta, q_0, F)$$ Where:

  1. $Q$: A finite, non-empty set of states.
  2. $\Sigma$: A finite alphabet of input symbols.
  3. $\delta$: The state transition function, mapping a state and an input symbol to exactly one state: $$\delta: Q \times \Sigma \to Q$$
  4. $q_0$: The unique initial (start) state, where $q_0 \in Q$.
  5. $F$: The set of final (accepting) states, where $F \subseteq Q$.

Extended Transition Function ($\hat{\delta}$)

To process an entire string $w \in \Sigma^*$ rather than an individual symbol, we define the extended transition function $\hat{\delta}: Q \times \Sigma^* \to Q$ recursively:

$$\begin{aligned} \text{Base Step: } & \hat{\delta}(q, \epsilon) = q \\ \text{Inductive Step: } & \hat{\delta}(q, x a) = \delta(\hat{\delta}(q, x), a), \quad \text{where } x \in \Sigma^* \text{ and } a \in \Sigma \end{aligned}$$

Language Accepted by a DFA: $$L(M) = \{ w \in \Sigma^* \mid \hat{\delta}(q_0, w) \in F \}$$

Quick Recall

DFA 5-tuple: $(Q, \Sigma, \delta, q_0, F)$. Determinism requires that $\delta(q, a)$ is defined for every symbol $a \in \Sigma$, with exactly one deterministic destination state.

Construct a DFA that accepts all binary strings representing integers divisible by 3 (reading MSB first): $$L = \{ w \in \{0, 1\}^* \mid \text{value}(w) \equiv 0 \pmod 3 \}$$
Step 1: Modular State Formulations

When appending a new bit $b \in \{0, 1\}$ to the right of an existing binary number with value $V$, the new value is $V_{\text{new}} = 2V + b$.

$$\text{New Remainder} = (2 \times \text{Current Remainder} + b) \pmod 3$$
  • State $q_0$: Remainder $0 \pmod 3$ (Initial & Accepting state).
  • State $q_1$: Remainder $1 \pmod 3$.
  • State $q_2$: Remainder $2 \pmod 3$.

  • From $q_1$ (rem 1): on 0 $\to (2(1)+0)\%3 = 2 \implies q_2$; on 1 $\to (2(1)+1)\%3 = 0 \implies q_0$.
  • From $q_2$ (rem 2): on 0 $\to (2(2)+0)\%3 = 1 \implies q_1$; on 1 $\to (2(2)+1)\%3 = 2 \implies q_2$.

§ 4

Nondeterministic Finite Automata (NFA)

A Nondeterministic Finite Automaton (NFA) relaxes the determinism constraints of DFAs. For a given state and input symbol, an NFA may transition to zero, one, or multiple next states simultaneously.

Formal 5-Tuple Definition of an NFA

An NFA is a 5-tuple: $$N = (Q, \Sigma, \delta, q_0, F)$$ Where the transition function maps to the power set of states: $$\delta: Q \times \Sigma \to 2^Q \quad (\text{or } \mathcal{P}(Q))$$ A string $w$ is accepted by an NFA if at least one computational path leading from $q_0$ upon reading $w$ halts in an accepting state $q_f \in F$.

Comparison: DFA vs. NFA

DimensionDeterministic Finite Automata (DFA)Nondeterministic Finite Automata (NFA)
Transition Range$\delta(q, a) \in Q$ (exactly one state)$\delta(q, a) \subseteq Q$ (subset of states, can be $\emptyset$)
$\epsilon$-TransitionsNot permittedPermitted in $\epsilon$-NFA

Computational PowerRecognizes Regular LanguagesIdentical power (Recognizes Regular Languages)
Execution Simulation$O(|w|)$ linear time in hardware/softwareRequires backtracking or set simulation ($O(|Q|^2 \cdot |w|)$)
Quick Recall

NFA transition function outputs a subset: $\delta: Q \times \Sigma \to 2^Q$. DFAs and NFAs recognize the exact same family of languages (Regular Languages).

§ 5

$\epsilon$-NFA & $\epsilon$-Closure

An $\epsilon$-NFA allows state transitions to occur spontaneously without consuming any input symbol ($\epsilon$-transitions).

Definition: $\epsilon$-Closure

For a state $q \in Q$, the $\epsilon$-closure of $q$ (denoted $\epsilon\text{-CLOSURE}(q)$) is the set of all states reachable from $q$ by traversing zero or more consecutive $\epsilon$-transitions:

  1. $q \in \epsilon\text{-CLOSURE}(q)$ (Every state belongs to its own $\epsilon$-closure).
  2. If $p \in \epsilon\text{-CLOSURE}(q)$ and $r \in \delta(p, \epsilon)$, then $r \in \epsilon\text{-CLOSURE}(q)$.
For a set of states $S \subseteq Q$: $$\epsilon\text{-CLOSURE}(S) = \bigcup_{q \in S} \epsilon\text{-CLOSURE}(q)$$

Quick Recall

$\epsilon$-transitions consume no input. $\epsilon\text{-CLOSURE}(q)$ finds all states reachable via $\epsilon$-edges alone (always includes $q$ itself).

§ 6

Equivalence of DFA and NFA: Subset Construction Algorithm

Rabin and Scott proved that every NFA can be converted into an equivalent DFA that accepts the exact same language. The conversion algorithm is called the Subset Construction Algorithm (or Powerset Construction).

The Subset Construction Algorithm

Given NFA $N = (Q_N, \Sigma, \delta_N, q_0, F_N)$, construct DFA $D = (Q_D, \Sigma, \delta_D, q_D, F_D)$:

  1. DFA Start State: $q_D = \{q_0\}$ (or $\epsilon\text{-CLOSURE}(q_0)$ for $\epsilon$-NFA).
  2. DFA States ($Q_D$): Subsets of $Q_N$ reachable from the start state ($Q_D \subseteq 2^{Q_N}$). Maximum theoretical states: $2^{|Q_N|}$.
  3. Transition Function: For any DFA state $S = \{p_1, \dots, p_k\}$ and input $a \in \Sigma$: $$\delta_D(S, a) = \bigcup_{p \in S} \delta_N(p, a)$$
  4. Accepting States ($F_D$): Any subset $S \in Q_D$ that contains at least one accepting state of the NFA: $$F_D = \{ S \in Q_D \mid S \cap F_N \neq \emptyset \}$$

Quick Recall

Subset construction creates DFA states representing sets of NFA states. If an NFA has $n$ states, the DFA has at most $2^n$ states (in practice, far fewer reachable states).

§ 7

Conversion of $\epsilon$-NFA to DFA

Converting an $\epsilon$-NFA to a DFA applies the same subset construction algorithm, with transitions filtered through $\epsilon$-closures:

$\epsilon$-NFA to DFA Transition Rule

1. DFA Initial State: $$q_D = \epsilon\text{-CLOSURE}(q_0)$$ 2. For each generated DFA state $S$ and input symbol $a \in \Sigma$: $$\delta_D(S, a) = \epsilon\text{-CLOSURE}\left( \bigcup_{p \in S} \delta(p, a) \right)$$ 3. Any DFA state containing at least one state from $F_N$ is accepting.

Quick Recall

For $\epsilon$-NFA conversion, take the $\epsilon$-closure before and after reading each symbol: $\delta_D(S, a) = \epsilon\text{-CLOSURE}(\delta(S, a))$.

§ 8

Real-World Applications of Finite Automata

Finite automata are foundational to practical computer science systems:

  • Compiler Lexical Analysis (Scanners): Tools like lex and flex convert regular expressions describing identifiers, keywords, numbers, and operators into DFAs to tokenize source code in $O(n)$ time.
  • Text Search & Pattern Matching: The UNIX grep utility and the Knuth-Morris-Pratt (KMP) / Aho-Corasick algorithms construct finite state automata to locate substrings in linear time without backtracking.
  • Network Protocol Verification: TCP connection handshakes (SYN, SYN-ACK, ACK, ESTABLISHED, FIN_WAIT) are modeled as DFAs to prevent deadlocks and enforce protocol correctness.
  • Hardware Design & Sequential Circuits: Digital logic controllers (traffic lights, vending machines, microprocessors) are designed as synchronous Mealy/Moore finite state machines.
Quick Recall

Applications: Lexical tokenizers (lex/flex), text search (grep/KMP), network protocols (TCP FSM), and digital circuit design.

2-Mark Questions

Q1. Define an alphabet and give an example.
An alphabet is a finite, non-empty set of symbols, typically denoted by $\Sigma$. Example: The binary alphabet $\Sigma = \{0, 1\}$.
Q2. Define the extended transition function of a DFA.
The extended transition function $\hat{\delta}: Q \times \Sigma^* \to Q$ processes an entire string $w$ recursively: $$\hat{\delta}(q, \epsilon) = q, \quad \hat{\delta}(q, xa) = \delta(\hat{\delta}(q, x), a)$$ Where $x \in \Sigma^*$ and $a \in \Sigma$.
Q3. If an NFA has n states, what is the maximum number of states in its equivalent DFA?
The maximum number of states in the equivalent DFA is $2^n$ (the size of the power set $\mathcal{P}(Q)$).
